# 구운몽: 한바탕 꿈 — 기획서 v2

2026-10-03 · 출세 시뮬레이션의 내용·연출·자산 배정 기록.

이 문서는 현재 코드와 데이터의 구성을 적는다. [기획서 v1](기획서_v1.md)은 이전 이야기 어드벤처의 기록으로 그대로 보존한다. 데이터 형식은 [내용 데이터 약속](../js/data/README.md), 작품 사실과 이본 차이는 [원작 검증 노트](research/01_원작_검증노트.md)를 따른다.
글과 장면은 실제 데이터의 본편 28단위와 선택형 비교 읽기로 구성한다. 공개판 교체는 로컬 검증과 별도로 진행한다.

## 1. 설계 목적과 지킬 경계

예고를 읽고 준비를 고르는 한곳에 독해 판단을 모은다. 꿈에서는 공·명성·재물을 쌓고, 깨어난 뒤 그 경험을 해석의 근거로 돌아본다.
대상은 공통국어2 「구운몽」을 읽는 고등학생이다. [10공국2-05-01]·[10공국2-05-02]·[10공국1-05-03]과 연결한다.

- 사건 순서·결말·벼슬·집 단계는 고정이다. 준비는 게임 속 훈련이며 원작과 다른 행동이나 결말을 선택하는 장치가 아니다.
- 능력·윤목·공·명성·재물·꿈 점수는 게임 설정이다. 점수로 성적이나 순위를 매기지 않는다.
- 인연은 등급의 보상이 아니며 소원·능력·점수를 채우지 않는다. 가춘운·적경홍의 속임수를 미리 간파하는 전개도 넣지 않는다.
- 미색은 꿈 내내 ?이며 인연 잇기에서만 드러낸다. 구슬을 놓쳐도 진행과 평가에 불이익이 없다.
- 지팡이 클릭 때 깨어남을 저장하며, 학생의 꿈 재진입은 막는다. 선생님용은 예외이고 전체 초기화에는 확인이 필요하다.
- 채점은 이본 공통 사실을 따른다. 영인 대조를 마친 글이 없어 현재 原文 낙관은 없다.

## 4. 꿈 밖 장면과 컷신 대본 요약

### 결과에서 선택해 읽는 「조신 설화」

꿈을 빌던 조신 → 꿈속 살림과 가난 → 아이를 잃는 고통 → 부부의 이별 직전 깨어남 → 희어진 머리와 돌미륵 → 수행으로 돌아감.
그림은 sc_josin_dream·sc_josin_wake 두 장이다. 본편을 마친 결과 화면에서 접힌 비교 읽기를 선택하면 그림과 풀이를 펼친다. 별개의 작품임과 비교 이유를 먼저 밝히며, 읽어도 진행·점수·해석을 바꾸지 않는다. 꿈속 햇수를 문제로 묻지 않는다.

### 1장 연화봉

돌다리에서 복숭아꽃이 구슬로 변하고 팔선녀가 떠난다. 선방에서 성진이 이름과 삶을 돌아본 뒤 소원 찾기로 넘어간다. 출장입상·부귀·미색·풍류·공명이 정답이며 물그릇·경전·염주는 현재 가진 것이라 오답이다.
대사는 성진을 꾸짖고, 저승의 지장보살과 환생의 양 처사는 서로 다른 역할로 서술된다. 얼굴이 없는 지장보살·양 처사는 대사창 인물 얼굴로 호출하지 않는다.

### 3장 깨어남

취미궁 높은 대에서 옛 궁터와 무덤을 보며 무상을 느낀다. 호승이 돌길을 두드리며 온 때는 아직 꿈이다. 소유는 남악에서 본 스님을 떠올리고 깨우침을 청한다.

1. c3-staff는 sc_c3_monk 위에서 안개와 배경 이동으로 시작한다.
2. 호승을 배치한 pause:'staff' 프레임에서 **0기준 2번 자세**를 고정한다. 여기서는 자동으로 타격하지 않고 건너뛰기도 없다.
3. 난간 치기 단추를 누르면 G.app.wake()가 먼저 awake·awakeAt을 저장한다. 호승은 **3번 자세**로 바뀌고 등록된 시트가 있으면 400ms 유지된다.
4. 말판·집·인연첩·점수의 부서짐을 보여 준 뒤 빈 선방으로 간다. 부서짐은 건너뛸 수 있다.

새 호승은 96×96 셀의 네 프레임 시트다. 자산이 없을 때도 얼굴·이름 대체 표시로 진행할 수 있다. 기록 속 최고값·사건 장부는 보존하지만 학생에게 꿈 화면을 다시 열어 주지 않는다.

### 4장 꿈 일지

다섯 짝을 한꺼번에 확인한다. 같은 소원을 여러 칸에서 쓸 수 있고 미색은 이 선택지에 넣지 않는다.

맞대기를 마치면 인연 잇기 선택을 연다. 어떤 마음을 고르든 미색을 공개하고, 찾은 구슬 카드는 팔선녀 쪽으로 뒤집는다. 놓친 구슬은 흐리게 남는다. 인연 잇기와 구슬은 채점하지 않는다.

### 5장 문답과 팔선녀 출가

성진의 감사 → 해석 1개·근거 1개 선택 → 대사의 응답 → 그대로 확정하거나 한 번 수정 → 법을 청함 → 팔선녀 출가와 결말 순서다.
출가 컷신은 sc_c5_ordination 한 장을 쓴다. 0·4·8·13초에 장면을 바꾸고 마지막 이동 4초를 포함해 자동 재생 기준 약 17초다. 출가 청원, 함께 가르침을 들음, 깨달음, 대사의 서역행과 극락이라는 흐름을 짧게 보여 준다. 삭발의 세부를 채점하거나 별도 활동으로 만들지 않는다.

## 8. 기록과 교사 디브리핑

채점 활동은 a-wish·j-match 두 개다. 사건 12행은 events에서 읽고 준비 적중·등급·예고 단서·선생님 도움을 표시한다. 장부는 총 14행이며 자동 준비 기록은 —로 남는다. 구슬 수는 결과의 별도 표시이고 인연 수와 꿈 점수는 장부에 넣지 않는다.
준비 선택과 윤목은 즉시 굳고, 등급·보상은 처음 끝낼 때 확정한다. 다시 보기에서는 기록을 더하지 않는다. 저장은 guunmong-v2이며 이전 v1은 읽거나 지우지 않는다.
결과 화면과 PNG에는 해석·근거·수정 흔적·소원·구슬·최고 꿈 점수→0 및 점수 평가 제외 안내를 담는다. 기기 밖 자동 전송은 없다.
