# tests — 자동 점검

## 맡는 것
완료 조건을 판정하는 node 점검 묶음. `run-all.mjs`가 `check-*.mjs`를 이름순으로 하나씩 돌리고 모두 0이면 0으로 끝난다.

| 파일 | 데이터 | 보는 것 |
| --- | --- | --- |
| `check-engine.mjs` | 임시(`?fixture=1`) | 장 진행, 이어 하기(3장 앞뒤), 깨어남 잠금과 선생님용 예외, 새로 시작, 도움 사다리·장부, 읽기 방식, 설정, 화면 접기, 글 표기, 곡 바뀜, 파일로 열기 |
| `check-dream.mjs` | 임시 | 말 걷기, 소원(미색 '?'), 인연첩, 집 놓기·옮기기, 구슬 놓치기, 깨어남과 사라짐, 꿈 일지, 해석 고치기, 결과 PNG |
| `check-content.mjs` | 실제 | 데이터 규칙·이름·原文 없음·금칙어·조사·교과서 15자 겹침(정적), 선생님용 없이 완주 세 판(휴대폰 처음 읽기, 태블릿 다시 읽기, 데스크톱 처음 읽기), 알림 위치, 명암비, 출처 문구, 소리, 실제 데이터 파일로 열기 |
| `check-assets.mjs` | 실제 | 가리키는 그림이 모두 있음, 바깥 요청 없음, 정수배, 화면 장식 사용, 화면 캡처 |
| `check-bgm.mjs` | `bgm.js` | mp3 파일·크기·비트율, 곡 이름 18개, 악구 번호, 출처, (ffmpeg) LUFS·봉우리 |
| `check-rights.mjs` | git | 추적 파일·모든 이력·커밋 글의 금지된 두 이름, 교과서 파일·기획 문서 폴더의 이력, `.gitignore`, 교과서 15자 겹침 |
| `fixtures/stub.js` | — | 모든 데이터 항목의 모양을 한 번씩 담은 작은 임시 데이터(글은 모두 `(임시)`) |

## 맡지 않는 것
- 게임 코드·데이터를 점검을 통과시키려고 여기서 흉내 내지 않는다. 점검이 실패하면 게임을 고친다.
- `shots/`(화면 캡처)와 `node_modules/`는 커밋하지 않는다.
- 점검 기준을 낮추는 고침은 그 까닭이 되는 게임 변경과 같은 커밋에서만 한다(예: 原文 대조를 마쳐 '原文 없음' 기준을 바꿀 때).

## 지켜야 할 것
- 점검 파일은 `check-<이름>.mjs`, 인자 없이 실행해 0/1로 끝나고, 실패마다 `✗ <어디>: <무엇>`을 찍는다. 어느 폴더에서 불러도 되게 경로는 `import.meta.url` 기준으로 잡는다.
- 화면 점검은 각자 `127.0.0.1`의 임의 포트(`listen(0)`)에 작은 정적 서버를 띄우고 설치된 Chrome(`channel: 'chrome'`, headless)으로 연다. 고정 포트를 쓰지 않는다.
- `/assets/` 404는 실패다(임시 데이터의 `stub_*` 같은 일부러 없는 파일만 예외). 바깥 주소 요청도 실패다.
- 금지된 두 이름은 점검 코드에도 글자로 쓰지 않는다. `check-rights.mjs`는 글자 번호로, `check-content.mjs`는 글자를 나누어 적는다. 새 점검도 같은 방법을 쓴다(권리 점검이 이 폴더도 검사한다).
- 교과서 본문 추출본은 `E:/github/고전 문학 게임/구운몽/design/source/교과서_본문추출.txt`(절대 경로)에서 읽는다. 작업 가지 폴더에서 돌려도 원래 폴더의 것을 본다. 없으면 겹침 점검만 건너뛴다.
- 완주 판은 선생님용 단추를 쓰지 않는다. 진행은 `#tray [data-act="next"]`와 `[data-must]` 표시를 따른다.
- 권리 점검은 `git ls-files`로 파일을 고르므로 새 파일은 스테이지한 뒤에 돌린다.

## 돌리기
- 처음 한 번: `cd tests; npm install`(playwright만. 브라우저는 설치된 Chrome).
- 작업 가지 폴더(worktree)에는 `tests/node_modules`가 없다. worktree 맨 위에서 `cmd /c mklink /J tests\node_modules "E:\github\고전 문학 게임\구운몽\tests\node_modules"`로 잇는다. 안 하면 `Cannot find package 'playwright'`로 끝난다.
- 전체 `node run-all.mjs`(10분 남짓), 하나 `node check-<이름>.mjs`, 내용 점검의 화면 판 하나 `ONLY=휴대폰`(또는 태블릿·데스크톱), 배경음 음량 건너뛰기 `--no-lufs`, ffmpeg 경로 `FFMPEG`.
- 끝낼 때는 언제나 `node run-all.mjs` 전체가 0이어야 한다.

## 새 점검을 더할 때
- 게임의 새 규칙에는 실제 데이터 쪽(check-content)과 임시 데이터 쪽(check-engine·check-dream) 가운데 재현이 확실한 쪽에 점검을 더한다. 임시 데이터에 새 항목 모양이 필요하면 `fixtures/stub.js`에 한 번씩 담는다.
- 헛도는 점검을 막는다: 확인 대상이 하나도 없으면(예: 완주 중 알림을 한 번도 못 봄) 실패로 본다.
