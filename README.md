# 구운몽: 한바탕 꿈

**만든이**: 박준일 (온양여자고등학교 국어 교사)

김만중의 「구운몽」을 **양소유의 한평생을 키우는 출세 시뮬레이션**으로 익히는 고등학생용 학습 게임입니다.
학생은 성진의 소원을 찾고, 꿈속 사건의 예고를 읽어 양소유가 무엇을 준비할지 고릅니다. 공·명성·재물과 집의 꾸밈이 쌓이다가, 호승의 지팡이가 난간을 치면 꿈의 화면이 사라집니다. 마지막에는 대사의 응답을 듣기 전후로 자신의 해석을 돌아봅니다.

학생이 작품에서 살펴볼 내용을 놀이의 과정에 담았습니다.

| 살펴볼 내용 | 게임 장치 |
| --- | --- |
| 사건을 이해하는 단서 | 한두 줄 예고를 읽고 두 번 준비한다. 사건 뒤에는 단서 낱말을 다시 짚는다 |
| 소원과 꿈의 관계 | 독백에서 소원 다섯을 찾고, 깨어난 뒤 꿈속 일을 소원과 맞댄다 |
| 인물마다 다른 사연 | 인연 카드에 이름·재주·만난 곳을 담는다. 인연을 점수나 소유물로 세지 않는다 |
| 꿈을 거쳐 돌아오는 짜임 | 꿈에서 수치를 쌓고, 깨어남 뒤 결과에 **최고 꿈 점수 → 0**을 남긴다 |
| 결말에 대한 주체적 해석 | 대사의 응답 전에 해석과 근거를 고르고, 들은 뒤 한 번 수정할 수 있다 |

- 별도 게임 설치나 계정 없이 브라우저에서 실행합니다. 휴대폰 세로 화면·태블릿·PC를 대상으로 만들었습니다.
- **한 차시 35~45분을 목표**로 설계했습니다. 아래 시간은 수업 배분안이며 학생 대상 실측값은 아닙니다.
- 진행 기록은 **해당 브라우저의 localStorage에만** 남습니다. 학생 기록을 서버로 전송하지 않습니다.
- 연계 성취기준: [10공국2-05-01], [10공국2-05-02], [10공국1-05-03].

## 실행하기

| 방법 | 설명 |
| --- | --- |
| 내 컴퓨터에서 | 저장소 폴더에서 `python -m http.server 8767`을 실행하고 `http://127.0.0.1:8767`을 연다 |
| 파일로 | `index.html`을 열어 실행한다. 게임 자체에는 빌드나 패키지 설치가 필요 없다 |
| 공개 주소 | https://pblsketch.github.io/guunmong/ |
| 바로가기 | `?ch=2`, `?scene=e03-geomungo`로 장·장면을 가리킨다. 학생은 아직 열리지 않았거나 깨어난 뒤 잠긴 장면으로 갈 수 없다 |
| 선생님용 | `?teacher=1`로 켜고 `?teacher=0`으로 끈다. 설정에서도 바꿀 수 있다 |

배경음·효과음·큰 글자는 설정에서 조절합니다. 전체 화면 단추도 있습니다. 소리는 브라우저의 사용자 입력 뒤 재생되며, 전체 화면 여부는 저장하지 않습니다.

## 구성 (한 차시 35~45분 목표)

기본 시간표의 합은 45분입니다. 읽는 속도와 대화 시간에 따라 조절합니다. **진행 단위는 총 29개**이며 장의 차례는 고정입니다.

| 장 | 내용 | 진행 단위 수 | 배분 시간 |
| --- | --- | ---: | --- |
| 0 서장 | 「조신 설화」 컷신으로 꿈속 삶과 깨어남을 먼저 본다 | 1 | 1분 |
| 1 연화봉 | 돌다리·선방·소원 찾기·꾸짖음·저승과 환생 | 5 | 3분 |
| 2 꿈 — 출세 시뮬레이션 | 사건 12개와 이음 장면 3개를 원작 차례로 지난다 | 15 | 30분 |
| 3 깨어남 | 취미궁의 무상·호승·지팡이·빈 선방 | 4 | 2분 |
| 4 꿈 일지 | 맞대기 다섯 칸, 인연 잇기, 구슬과 팔선녀 | 1 | 3분 |
| 5 육관대사 | 해석과 근거 선택·응답·한 번 고치기·출가 컷신 | 2 | 4분 |
| R 결과 | 꿈 일지 마지막 장, 장부, 생각 나눔, 작품 노트 | 1 | 2분 |

## 놀이 방법

1. 1장 독백에서 앞으로 누리고 싶은 삶을 나타내는 소원 낱말 다섯을 찾습니다.
2. 꿈의 사건마다 예고를 읽고 **학문·거문고·검술·병법 중 두 번** 준비합니다. 같은 행동을 두 번 골라도 됩니다.
3. 고른 능력이 윤목 값 1~3과 기본 상승분만큼 오릅니다. 선택과 윤목은 즉시 저장되므로 새로 고침해도 다시 뽑지 않습니다.
4. 대사창으로 사건을 보고, 등급과 자원 보상을 확인합니다. 이어서 예고의 단서를 짚고 말판을 이동합니다.
5. 깨어난 뒤 꿈 일지와 해석을 정리하고 결과를 그림으로 저장합니다.

| 준비 행동 | 오르는 능력 |
| --- | --- |
| 학문 | 문장 |
| 거문고 | 음악 |
| 검술 | 무예 |
| 병법 | 지략 |

등급은 **빛나는 성공·훌륭한 성공·아쉬운 성공**입니다. 두 준비가 모두 핵심 능력에 맞으면 늘 빛나는 성공이며, 둘 다 빗나가면 빛나는 성공은 나오지 않습니다. 핵심 능력이 둘인 사건은 어느 쪽을 골라도 적중입니다. **실패·게임 오버·감점은 없고, 사건의 결말과 벼슬·집 단계는 모든 학생에게 같습니다.**

- **꿈 점수**는 공+명성+재물입니다. 이야기의 쌓임과 사라짐을 느끼는 장치이며 성적이나 등수로 쓰지 않습니다.
- **집**은 객사·초가 → 정 사도 댁 별당 → 승상부 → 취미궁 순서입니다. 물건 14개는 자동으로 장식되고, 재물은 같은 단계 안의 꾸밈을 바꿉니다.
- **소원** 중 출장입상은 대원수·승상 칸, 부귀는 재물, 공명은 명성, 풍류는 두 악기와 음악 사건으로 채웁니다. **미색은 꿈 내내 `?`**이며 일지의 인연 잇기에서 드러납니다.
- **인연**은 등급에 따라 달라지지 않고 능력·점수·게이지에 더해지지 않습니다. 가춘운·적경홍의 장난에서도 소유는 원작대로 속습니다.
- **구슬 찾기**는 선택입니다. 놓쳐도 진행되며 감점은 없습니다. 그림 가장자리가 잘린 화면에서는 [그림 살피기]로 확인할 수 있습니다.
- **깨어남**은 [지팡이로 난간을 친다]를 누를 때 기록됩니다. 들어 올린 자세에서는 기다리고, 친 뒤에는 부서짐 연출을 건너뛸 수 있습니다. 학생은 깨어난 뒤 꿈으로 돌아갈 수 없으며, 되돌리려면 확인을 거쳐 전체 진행을 지워야 합니다.

기록 열쇠는 `guunmong-v2`입니다. 이전 `guunmong-v1` 기록은 읽거나 삭제하지 않으므로 새 판은 처음부터 시작합니다. 준비 도중 종료하면 남은 턴부터, 준비를 마친 뒤 종료하면 사건 첫 줄부터 이어집니다. 깨어나기 전 3장에서 종료하면 취미궁부터, 깨어남이 저장됐으면 빈 선방 이후부터 이어집니다.

## 실제와 설정의 구분

| 표시 | 뜻 |
| --- | --- |
| 붉은 낙관 `原文` | 영인 대조를 끝낸 글에만 붙이는 표시. 현재는 해당 글이 없어 표시하지 않는다 |
| 한지 바탕 **풀이** | 게임을 위해 다시 쓴 현대어 서술과 대사 |
| 청록 `게임 설정` | 준비·윤목·능력·꿈 점수, 말판과 자동 장식, 구슬 배치 등의 장치. 처음에는 실제 작품과 다른 점도 안내한다 |
| 황토 `이본 노트` | 판본에 따라 달라지는 세부. 공통 사실을 묻는 정답 근거로 쓰지 않는다 |
| 쪽빛 `해석` | 읽는 이의 판단이 필요한 내용. 정답으로 채점하지 않는다 |

원작 순서·벼슬·인연의 근거는 [원작 검증 노트](design/research/01_원작_검증노트.md)에 정리돼 있습니다. 정답은 을사본 한문 계열과 한글 완판본의 공통 사실을 따릅니다. 정경패의 탄생 명주는 한문 계열에서 확인됐고 완판 대조는 미확인이며, 난양공주의 탄생 꿈은 두 계열에 있습니다. 모든 만남에 구슬을 숨기는 방식은 게임 설정입니다.

물건을 집에 표시하는 것이 모두 원작의 소유·보관 관계를 뜻하지는 않습니다. 천리마·비수·물병·하사품 궤짝처럼 장식으로 옮긴 경우 설명에서 구별합니다. 기린각 초상은 승상 사건의 내용이며 물건으로 받지 않습니다.

## 선생님용

- 모든 장과 사건을 열 수 있습니다. 사건에 바로 가면 앞선 미기록 사건을 **보통 준비**로 채웁니다. 기존 기록은 덮어쓰지 않고, 자동으로 채운 사건은 장부에 `—`로 남습니다.
- 보통 준비는 핵심 능력 행동 한 번과 정해진 비핵심 행동 한 번입니다. 준비 화면의 [핵심 능력 보기]는 장부에 선생님 도움으로 기록됩니다.
- 소원 찾기·맞대기에는 [정답 채우기]와 [정답 보기]가 있습니다. 풀기 전에 교사 도움을 쓰면 첫 시도는 기록 없음으로 남습니다.
- [화면 접기]로 화면을 가리고 소리를 멈출 수 있습니다.
- 소원 찾기와 맞대기가 채점 활동입니다. 구슬 찾기·인연 잇기·해석 선택은 채점하지 않습니다. 오답 뒤에는 표시·여백 메모·정답 안내로 도움을 받습니다.

**장부는 14행**입니다. 소원 찾기와 맞대기는 첫 시도·도움 사용을, 사건 12개는 준비 적중 0·1·2와 등급·단서·교사 도움을 읽습니다. 꿈 점수는 장부에 넣지 않습니다. 찾은 구슬 수는 결과의 별도 기록이며 점수로 치지 않습니다.

결과 화면과 저장 그림에는 선택한 해석·근거·고친 흔적, 소원 목록, 구슬, **꿈에서 쌓은 것 N → 깨고 남은 것 0**과 **점수로 평가하지 않아요**가 담깁니다. 이름은 선택입니다. 수업 뒤에는 어떤 단서로 준비했는지, 대사의 말을 듣고 생각을 바꾼 이유가 무엇인지 나눠 보세요. 공용 기기는 사용 뒤 확인을 거쳐 기록을 지웁니다.

## 만든 방법

- **설계**: [기획서 v2](design/기획서_v2.md)에 현재 구성을 적고, [기획서 v1](design/기획서_v1.md)은 이전 판 기록으로 보존합니다.
- **코드**: 빌드 없는 HTML·CSS·순수 JavaScript입니다. `js/core/`는 저장·내용 로딩·육성 규칙·표시를, `js/game/`은 장 진행과 화면을 맡습니다.
- **그림**: Codex CLI의 내장 이미지 생성으로 원본을 만들고 참조 그림으로 옷과 얼굴을 맞췄습니다. 인물은 당나라 옷을 입으며 그림 안에 글자는 넣지 않습니다. 배포용 그림은 **141개**, 32색 이하이며 WebP는 무손실, 아이콘은 PNG입니다.
- **동작 시트**: 준비 4종과 호승은 **96×96 셀 네 개를 가로로 놓은 384×96 시트**입니다. 준비 화면의 목표 표시 크기는 약 96 CSS px입니다. 능력·자원 아이콘 7개는 32×32입니다. 말판의 기존 걷기 시트는 별도의 32×32 셀입니다.
- **96px 결정**: 2026-10-03에 32·64·96 비교 후 같은 생성 원본을 96px로 다시 가공했습니다. 이전 32px 동작 후보는 게임에 넣지 않았습니다. 생성 당시 프롬프트의 32px 표현은 당시 요청을 기록한 것이며, 96px 생성 프롬프트로 고쳐 쓰지 않았습니다.
- **재현 자료**: `tools/manifest_sim96.json`에 원본·승인 파일·보존 프롬프트의 경로와 해시가 있습니다. 원본, 32px 후보, 96px 후보와 검토 자료는 `assets/raw/sim-v2/`에 별도 보존하며 git에는 넣지 않습니다. 해당 원본이 있는 작업 환경에서 아래 가공 명령을 씁니다. 가공 도구는 후보를 만들며 제품 파일을 자동 덮어쓰지 않습니다.

```text
python tools/process_sim_assets.py --manifest tools/manifest_sim96.json
python tools/check_assets.py
node tests/check-data.mjs
node tests/check-sim.mjs
node tests/check-dream.mjs
node tests/check-chapters.mjs
node tests/check-rights.mjs
```

- **음원**: 기존 국악 악구를 이어 붙인 18곡을 장면에 다시 배정했습니다. `tools/make_bgm.py`는 원음이 있는 환경에서 음원과 `bgm.js`를 만듭니다. 효과음은 브라우저 합성이며 녹음을 불러오지 못하면 합성 가락으로 대체합니다.
- **글꼴**: 갈무리와 Noto Serif KR의 부분 글꼴입니다. 사용권은 SIL OFL 1.1이며 `assets/fonts/OFL.txt`에 있습니다.
- **점검**: 개발용 `tests/` 의존성과 설치된 Chrome을 사용하는 검사들입니다. 전체 완료 기준 명령은 `node tests/run-all.mjs`입니다. 2026-10-03 검증 코드 `a09d3c0`에서 전체 9/9가 종료 코드 0으로 통과했습니다. 공개판은 배포 후 실제 주소에서 별도로 확인합니다.

## 음원 출처

배경음은 **국립국악원 「디지털 이음」 국악기 연주 음원(악구), 공공누리 제1유형·출처표시**를 이용했습니다. 원음은 국립국악원 누리집 https://www.gugak.go.kr/digitaleum/ 에서 제공하며, 게임에서는 악구를 연결하고 음량을 조절했습니다. 사용한 악구 번호는 `js/data/bgm.js`에, 장면별 배정은 기획서 v2에 있습니다.
