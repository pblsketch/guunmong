# 구운몽: 한바탕 꿈

**만든이**: 박준일 (온양여자고등학교 국어 교사)

김만중의 「구운몽」을 **공간을 걷고 인물과 대화하며 익히는 이야기 RPG**로 만든 고등학생용 학습 게임입니다.
학생은 성진의 소원을 찾고 양소유가 되어 시전·악기·물건과 인연이 이어지는 삶을 따라갑니다. 호승의 지팡이가 난간을 치면 처음의 선방으로 돌아와, 대사의 응답을 듣기 전후로 자신의 해석을 돌아봅니다.

학생이 작품에서 살펴볼 내용을 놀이의 과정에 담았습니다.

| 살펴볼 내용 | 게임 장치 |
| --- | --- |
| 사건을 이해하는 단서 | 가까이 다가가 관찰·대화하고 시를 전하거나 악기를 연주하는 원작 행동을 한다 |
| 소원과 꿈의 관계 | 독백에서 소원 다섯을 찾고, 깨어난 뒤 사건·물건·벼슬을 소원과 맞댄다 |
| 인물마다 다른 사연 | 인연 카드에 이름·재주·만난 곳을 담는다. 인연을 점수나 소유물로 세지 않는다 |
| 꿈을 거쳐 돌아오는 짜임 | 취미궁을 살펴본 뒤 처음과 같은 선방으로 돌아와 공간과 인물의 변화를 돌아본다 |
| 결말에 대한 주체적 해석 | 대사의 응답 전에 해석과 근거를 고르고, 들은 뒤 한 번 수정할 수 있다 |

- 별도 게임 설치나 계정 없이 브라우저에서 실행합니다. 휴대폰·태블릿·PC를 대상으로 만들었습니다. 세로를 기본으로 두며 가로에서도 사용할 수 있고 방향을 강제로 잠그지 않습니다.
- **한 차시 35~45분을 목표**로 설계했습니다. 아래 시간은 수업 배분안이며 학생 대상 실측값은 아닙니다.
- 진행 기록은 **해당 브라우저의 localStorage에만** 남습니다. 학생 기록을 서버로 전송하지 않습니다.
- 연계 성취기준: [10공국2-05-01], [10공국2-05-02], [10공국1-05-03].

## 실행하기

| 방법 | 설명 |

| 파일로 | `index.html`을 열어 실행한다. 게임 자체에는 빌드나 패키지 설치가 필요 없다 |

| 선생님용 | `?teacher=1`로 켜고 `?teacher=0`으로 끈다. 설정에서도 바꿀 수 있다 |

2026-10-05 탑다운 개편을 공개했습니다. 공개 주소에서 런타임 파일 231개의 원본 내용과 학생 도입 플레이·보따리·저장·재접속·두 탭 권한 이전을 확인했습니다. 설치된 Chrome의 가로·세로 화면 검사이며, 실제 학생 수업과 실기기 검증은 별도입니다.

배경음·효과음·큰 글자는 설정에서 조절합니다. 전체 화면 단추도 있습니다. 소리는 브라우저의 사용자 입력 뒤 재생되며, 전체 화면 여부는 저장하지 않습니다.

## 놀이 방법

1. 돌다리에서 성진을 움직여 가까운 인물과 대화합니다. 선방에서는 앞으로 누리고 싶은 삶을 나타내는 소원 낱말 다섯을 찾습니다.
2. 휴대폰은 화면 왼쪽을 누른 채 끌어 걷고, 가까이 가면 나타나는 오른쪽 노란 단추로 말 걸기·살펴보기를 합니다. 화면이나 인물·물건을 눌러 이동하는 방법도 유지합니다. PC는 방향키/WASD와 E·Enter·Space를 사용합니다. 도착만으로 사건이 끝나지 않으며 접힌 조작 도구의 대상 목록도 같은 행동으로 이어집니다.
3. 원작 차례로 시를 전하고 악기를 연주하며 물건과 사람의 반응을 살핍니다. 선택 관찰과 구슬 찾기는 다음 사건을 막지 않습니다.
4. 호승의 난간 타격을 누르면 깨어남이 저장되고 처음과 같은 선방의 성진으로 돌아옵니다. 꿈의 공간·생활 도구는 다시 열리지 않습니다.
5. 꿈 일지에서 소원과 사건을 맞대고, 대사의 응답 전후로 해석과 근거를 정리합니다. 결과를 PNG로 기기에 저장할 수 있습니다.

필드는 게임 화면을 채웁니다. 대화·소원·일지·해석·결과는 게임 안의 창에서 진행하며 긴 글은 창 안에서 읽습니다. 대화나 설정 중에는 이동이 멈춥니다. 큰 글자에서도 선택과 진행 단추를 사용할 수 있습니다.

- **생활 공간**은 객사·초가 → 정 사도 댁 별당 → 승상부 → 취미궁 순서입니다. 승상부는 대승상 임명 뒤에 열립니다. 재화에 따른 꾸밈과 직접 배치는 없으며 원작 물건 14개는 사건과 일지의 근거로 이어집니다.
- **소원** 중 출장입상은 대원수·승상 임명, 부귀는 기린 도포·옥대, 풍류는 두 악기, 공명은 기린각 초상을 근거로 채웁니다. **미색은 꿈 내내 `?`**이며 일지의 인연 잇기에서 드러납니다.
- **인연**은 수치·개수·보상·소원 채움으로 다루지 않습니다. 가춘운·적경홍의 속임수도 원작대로 겪으며, 난양공주를 혼례 전에 직접 만나지 않습니다.
- **구슬 찾기**는 선택입니다. 놓쳐도 진행되며 감점은 없습니다. 지도의 인접한 칸에서 찾거나 대상 목록을 이용합니다.
- **깨어남**은 [지팡이로 난간을 친다]를 누를 때 저장됩니다. 저장에 실패하면 들어 올린 자세로 기다리며 다시 시도할 수 있습니다. 학생이 꿈으로 돌아가는 길은 확인을 거쳐 전체 진행을 지우는 것뿐입니다. 백룡담에서 진영으로 돌아오는 작은 꿈은 전체 깨어남과 다릅니다.
- 준비 두 턴·윤목·성장 점수·등급은 새 플레이에 없습니다. 소원 찾기와 맞대기의 정오답은 학습 기록으로 남으며, 원작의 결말과 벼슬·생활 공간의 순서는 모든 학생에게 같습니다.

기록 열쇠는 `guunmong-v2`입니다. 옛 v2의 준비·능력·등급과 활동·해석·깨어남 기록은 보존하며 새 행동을 한 것으로 바꾸지 않습니다. 부분 준비 기록은 해당 체험의 안전 입구에서 이어집니다. `guunmong-v1`은 읽거나 삭제하지 않습니다. 이동 중 종료하면 마지막 저장 칸에서, 깨어나기 전 3장에서 종료하면 취미궁부터 연출을 다시 보고, 타격이 저장된 뒤에는 선방 이후부터 이어집니다.

같은 브라우저의 같은 기록은 한 탭에서만 진행·저장합니다. 다른 탭은 읽기 전용이며 진행 중인 탭을 닫은 뒤 이어 하기를 눌러 최신 기록을 엽니다. 저장 권한을 얻지 못한 환경에서는 안내를 표시하고 저장 가능한 플레이를 열지 않습니다.

## 실제와 설정의 구분

| 표시 | 뜻 |
| --- | --- |
| 붉은 낙관 `原文` | 영인 대조를 끝낸 글에만 붙이는 표시. 현재는 해당 글이 없어 표시하지 않는다 |
| 한지 바탕 **풀이** | 게임을 위해 다시 쓴 현대어 서술과 대사 |
| 청록 `게임 설정` | 이동 동선·공간 배치·상호작용 표현과 구슬 배치 등의 연출. 작품의 사실과 구분해 안내한다 |
| 황토 `이본 노트` | 판본에 따라 달라지는 세부. 공통 사실을 묻는 정답 근거로 쓰지 않는다 |
| 쪽빛 `해석` | 읽는 이의 판단이 필요한 내용. 정답으로 채점하지 않는다 |

원작 순서·벼슬·인연의 근거는 [원작 검증 노트](design/research/01_원작_검증노트.md)에 정리돼 있습니다. 정답은 을사본 한문 계열과 한글 완판본의 공통 사실을 따릅니다. 정경패의 탄생 명주는 한문 계열에서 확인됐고 완판 대조는 미확인이며, 난양공주의 탄생 꿈은 두 계열에 있습니다. 모든 만남에 구슬을 숨기는 방식은 게임 설정입니다.

물건 카드가 모두 원작의 소유·보관 관계를 뜻하지는 않습니다. 천리마·비수·물병·하사품 궤짝처럼 사건의 흔적을 담은 경우 설명에서 구별합니다. 기린각 초상은 승상 사건의 내용이며 물건으로 받지 않습니다.

## 선생님용

- 모든 장을 열 수 있습니다. 바로가기는 앞선 미기록 장면을 자동 안내로 남기며, 부분·완료 기록은 덮어쓰지 않습니다. 자동 안내는 학생의 실제 수행과 구분합니다. 지팡이 타격은 자동 안내로 대신하지 않습니다.
- 소원 찾기·맞대기에는 [정답 채우기]와 [정답 보기]가 있습니다. 풀기 전에 교사 도움을 쓰면 첫 시도는 기록 없음으로 남고, 교사 도움 흔적은 보존됩니다.
- [화면 접기]로 화면을 가리고 소리를 멈출 수 있습니다. 읽기 전용 탭에서는 선생님용도 기록·설정을 저장하지 못합니다.
- 소원 찾기와 맞대기가 채점 활동입니다. 구슬 찾기·인연 잇기·해석 선택은 채점하지 않습니다. 오답 뒤에는 표시·여백 메모·정답 안내로 도움을 받습니다.

**장부는 14행**입니다. 소원 찾기와 맞대기는 첫 시도·도움을, 사건 12개는 미시작·진행·완료·자동 안내와 살펴본 행동 근거·도움을 보여 줍니다. 옛 등급으로 마친 사건은 **이전 기록**으로 구분하며 새 수행 완료로 바꾸지 않습니다. 구슬 수는 별도 기록이며 점수가 아닙니다.

결과 화면과 900px 너비 PNG에는 취미궁과 선방의 대비, 선택한 해석·근거·고친 흔적, 소원·구슬·도움 안내가 담깁니다. 이름은 선택입니다. 화면에 쓴 이름을 저장하지 못하면 그림 저장도 멈추고 재시도를 안내합니다. 저장 버튼을 누른 시점의 결과를 사용하며, 기다리는 동안 화면을 떠나거나 기록을 초기화하면 늦은 다운로드를 취소합니다.

수업 뒤에는 어떤 장면·물건이 소원을 보여 주는지, 같은 선방이 어떻게 다르게 느껴지는지, 대사의 말을 듣고 생각을 바꾼 근거가 무엇인지 나눠 보세요. 공용 기기는 사용 뒤 확인을 거쳐 기록을 지웁니다.

| `notes.js` | 작품·이본·교사 안내, 생각 나눔, 화면 문구 |
| `sprites.js` | 승인된 그림 파일과 셀 크기·프레임 수 |
| `bgm.js` | 음원 파일·악구·출처. `tools/make_bgm.py`로만 생성 |

장면의 곡은 `scenes.js`의 `bgm`으로 배정합니다. 곡 정보 파일인 `bgm.js`를 손으로 편집하지 않습니다. 해석 근거를 줄이면 실제 대사도 같은 문자열로 맞춥니다. 이야기 글은 `G.storyText`의 한글 음절 셈으로 **4,400자 이하**를 지킵니다. 화면 글에 새 글자가 생기면 `python tools/build_fonts.py`로 부분 글꼴을 다시 만듭니다.

## 만든 방법

- **설계 이력**: [기획서 v1](design/기획서_v1.md)과 [기획서 v2](design/기획서_v2.md)는 이전 판 기록으로 보존합니다. 현재는 원작 공간에서 행동하며 사건을 따라가는 구성입니다.
- **코드**: 빌드 없는 HTML·CSS·순수 JavaScript입니다. `js/core/`는 저장·내용 로딩·체험·보행 규칙·표시를, `js/game/`은 장 진행과 화면을 맡습니다.
- **그림**: 승인된 Codex CLI 및 내장 image_gen 생성 원본을 사용합니다. 인물은 당나라 옷을 입으며 그림 안에 글자는 넣지 않습니다. 승인된 제품 그림은 **161개**(기존 141개·탑다운 16개·정지 NPC 3개·여도사 걷기 1개)입니다. 32색 이하이며 WebP는 무손실, 아이콘은 PNG입니다.
- **동작 규격**: 탑다운 걷기는 32×32 셀 5열×4행으로 네 방향을 표현합니다. 정지 NPC는 32px 한 셀이며, 호승 지팡이는 기존 **96px 셀 네 프레임**을 유지합니다. 준비 네 동작·능력/자원 아이콘·말판 말은 구판 자산으로 보존하며 새 준비 화면에서 쓰지 않습니다.
- **96px 결정**: 2026-10-03 같은 생성 원본의 32·64·96 비교 뒤 준비·지팡이 동작을 96px로 가공했습니다. 생성 당시 프롬프트와 이전 후보는 바꾸거나 지우지 않았습니다.
- **재현 자료**: `tools/manifest_sim96.json`, `manifest_topdown_approved.json`, `manifest_rpg_npcs_approved.json`, `manifest_rpg_disguise_approved.json`에 승인 파일·원본·프롬프트·해시가 있습니다. 원본과 후보는 `assets/raw/`에 보존하며 git에 넣지 않습니다. 새 생성·교체는 사용자 검토와 승인을 거칩니다. 아래 가공 명령은 구판 준비·현행 지팡이 원본이 있는 환경에서 후보만 만들며 제품 파일을 덮어쓰지 않습니다.

```text
python tools/process_sim_assets.py --manifest tools/manifest_sim96.json
python tools/check_assets.py
node tests/check-data.mjs
node tests/check-sim.mjs
node tests/check-dream.mjs
node tests/check-chapters.mjs
node tests/check-rights.mjs
```

- **음원**: 기존 국악 악구를 이어 붙인 18곡을 장면에 다시 배정했습니다. `tools/make_bgm.py`는 원음이 있는 환경에서 음원과 `bgm.js`를 만듭니다. 효과음은 브라우저 합성이며 녹음을 불러오지 못하면 합성 가락으로 대체합니다.
- **글꼴**: 갈무리와 Noto Serif KR의 부분 글꼴입니다. 사용권은 SIL OFL 1.1이며 `assets/fonts/OFL.txt`에 있습니다.
- **점검**: 개발용 `tests/` 의존성과 설치된 Chrome을 사용하는 검사들입니다. 전체 완료 기준 명령은 `node tests/run-all.mjs`입니다. 2026-10-05 첫 화면·모바일 조작 보완까지 반영한 코드 `fac1614`에서 전체 **10/10, 종료 코드 0**을 확인했습니다. 원본은 `tests/shots/run-all-2026-10-05T12-45-23-117Z.log`입니다. 누적 독립 검토의 남은 지적은 0건이며, 이 결과는 실제 학생·실기기·공개 주소 검증이 아닙니다. 2026-10-04 `c928ef3`의 9/9는 이전 육성판의 검증 이력입니다.
