# 구운몽: 한바탕 꿈

**만든이**: 박준일 (온양여자고등학교 국어 교사)

김만중의 「구운몽」을 **승경도 말판 위에서 한평생을 사는 이야기 어드벤처**로 익히는 고등학생용 학습 게임입니다.
학생은 연화봉의 젊은 승려 성진이 되어 팔선녀를 만난 뒤 번뇌에 빠지고, 양소유로 다시 태어나 말판 위에서 벼슬을 올리며 집을 꾸밉니다. 그러다 지팡이 소리 한 번에 모든 것이 사라진 빈 선방에서 꿈을 되짚고, 육관대사의 물음 앞에서 자기 해석을 고릅니다.

학생들이 이 작품을 어려워하는 점을 게임의 조작으로 바꿨습니다.

| 어려운 점 | 게임 장치 |
|---|---|
| 꿈과 현실의 짜임(환몽 구조)이 머리로만 이해된다 | 꿈속에서 벼슬·물건·집을 직접 쌓았다가, 깨어나는 순간 **한꺼번에 사라지는 것**을 겪는다 |
| 꿈이 성진의 어떤 마음에서 나왔는지 잇기 어렵다 | 1장에서 성진의 독백으로 **소원 목록**(출장입상·부귀·미색·풍류·공명)을 만들고, 4장 **꿈 일지**에서 꿈속 사건을 소원과 맞댄다 |
| 등장인물이 많고 여덟 여인이 뒤섞인다 | 여인마다 사연과 능력이 적힌 **인연첩** 카드, 처음 만나는 장면마다 숨은 **여덟 구슬**(찾으면 깨어난 뒤 팔선녀의 정체가 풀림) |
| 결말의 뜻이 "인생무상" 한 줄로 외워진다 | 대사의 대답을 듣기 **전에** 해석을 고르고, 들은 뒤 한 번 고칠 수 있다. 고친 흔적이 결과 화면에 남는다 |

- 브라우저만 있으면 됩니다(설치 없음). 휴대폰(세로)·태블릿·PC를 모두 지원합니다.
- **한 차시(약 44분)**에 처음부터 결과 화면까지 끝납니다. 다시 읽기는 약 35분입니다.
- 진행 상황은 **그 브라우저에만** 저장됩니다(서버로 보내지 않음).

## 구성 (한 차시 약 44분)

| 장 | 내용 | 활동 | 시간 |
|---|---|---|---|
| 서장 | 「조신 설화」: 꿈속 한평생을 짧게 미리 겪기 | 짧은 읽기 활동 | 3분 |
| 1장 연화봉 | 석교의 팔선녀, 선방의 독백, 대사의 꾸짖음, 저승과 환생 | **소원 목록 찾기**, 저승·환생 대목 읽기 | 7분 30초 |
| 2장 꿈 — 승경도 | 꿈 장면 14개를 원작 순서로 지나며 말이 벼슬 칸을 오른다 | 장면마다 짧은 읽기 활동, 마음 고르기(채점 없음), 집에 물건 놓기, 숨은 구슬 | 13분 40초 |
| 3장 깨어남 | 취미궁의 탄식, 호승의 정체, 지팡이로 난간을 침 → 빈 선방 | 취미궁·호승 대목 읽기 | 6분 30초 |
| 4장 꿈 일지 | 꿈과 소원 맞대기, '해석' 짝, 미색 칸이 드러나는 순간, 구슬과 팔선녀 | 맞대기(분명한 짝만 채점) | 5분 |
| 5장 육관대사 | 성진과 대사의 문답, 팔선녀의 출가와 결말 | **해석 고르기와 한 번 고치기**(채점 없음) | 5분 30초 |
| 결과 | 꿈 일지 마지막 장(이름·해석·근거·고친 흔적), 장부, 오답 노트, 생각 나눔 질문, 작품 노트 | 이미지 저장 | 2분 |

- **승경도 말판**: 칸은 양소유가 원작에서 실제로 거친 벼슬과 장소뿐입니다. 윤목 굴리기와 떨어지는 칸은 없고, 장면을 마치면 말이 원작대로 다음 칸으로 갑니다.
- **집**: 객사·초가 → 정 사도 댁 별당 → 승상부 → 취미궁 순으로 커집니다. 장면마다 얻는 원작 속 물건 하나를 학생이 마음대로 놓습니다(채점 없음).
- **여덟 여인**은 '인연'으로 따로 다룹니다. 소원 칸을 채우지 않고, 개수로도 세지 않습니다. 소원 목록의 **미색** 칸은 꿈 내내 '?'로 비어 있다가 꿈 일지에서야 드러납니다.
- **깨어난 뒤에는 꿈으로 돌아갈 수 없습니다**(뒤로 가기·새로 고침·목차·주소 모두). 다시 꿈꾸려면 처음부터 새로 시작합니다.

## 두 가지 읽기 방식

| 방식 | 대상 | 차이 |
|---|---|---|
| 처음 읽기 | 작품을 처음 만나는 학생 | 풀이가 보이고, 인물 이름 옆에 얼굴이 나오고, 장마다 '지난 이야기'가 나옴 |
| 다시 읽기 | 작품을 읽은 학생(복습) | 풀이를 가리고, 얼굴·지난 이야기가 없으며, 활동에 헷갈리는 선택지가 더 들어감 |

## 실제와 설정의 구분

| 표시 | 뜻 |
|---|---|
| 붉은 낙관 `原文` | 한문본 회목과 핵심 구절. **영인본과 한 글자씩 맞대어 본 뒤에만** 붙입니다. 지금은 아직 대조 전이라 原文 표시 없이 풀이만 나옵니다 |
| 한지 바탕 **풀이** | 이 게임을 위해 새로 쓴 현대어. 번역서·교과서·시험 지문의 문장은 쓰지 않았습니다 |
| 청록 `게임 설정` | 승경도 말판, 소원 목록의 형식, 집 꾸미기, 여섯 구슬의 자리(정경패·난양공주의 구슬만 원작에 흔적이 있음), 웃음 연출. 처음 나올 때 "실제로는 →"을 함께 보여 줍니다 |
| 황토 `이본 노트` | 판본마다 내용이 다른 곳 |
| 쪽빛 `해석` | 여러 해석이 있는 것. 채점하지 않습니다 |

- 정답 판정에는 **한문본(을사본 계열)과 한글 방각본에 모두 있는 사실만** 썼습니다. 근거와 출처는 `design/research/01_원작_검증노트.md`에 있습니다.
- 그림 속 인물은 배경에 맞춰 **당나라 옷**을 입습니다. 그림에는 글자를 넣지 않았습니다.

## 선생님용

- `?teacher=1` 또는 설정에서 켭니다. 모든 장(깨어난 뒤 포함)이 열리고, 활동마다 [정답 채우기]·[정답 보기]가 생깁니다. 이렇게 푼 활동은 장부에 '도움 사용(선생님용)'으로 남습니다.
- **화면 접기**: 화면을 덮고 소리를 멈춥니다.
- 게임 오버·시간 제한·감점이 없습니다. 틀리면 틀린 칸 표시 → 여백 메모 → 정답 보기 순서로 도움이 열리고, 장부에는 첫 시도 정확도와 도움 사용만 남습니다.
- 채점하지 않는 것: 마음 고르기, 집 배치, 구슬 찾기, '해석' 짝, 해석 고르기.
- 교사용 안내(수업에 넣을 시점: 공통국어2 「구운몽」 단원, 예상 시간, 끝난 뒤 물을 질문)는 선생님용 목차에 있습니다. 결과 화면의 **꿈 일지 마지막 장**(이미지 저장)과 생각 나눔 질문을 디브리핑에 쓰세요.

### 내용 고치기

학습 내용은 모두 `js/data/`의 데이터 파일에 있어 코드를 몰라도 고칠 수 있습니다. 형식은 `js/data/README.md`에 적혀 있습니다.

| 파일 | 내용 |
|---|---|
| `scenes.js` | 장면마다 풀이, 활동(칸·정답·헷갈리는 선택지), 마음 선택지, 물건, 구슬 자리 |
| `chapters.js` · `board.js` | 장 구성, 말판 칸(벼슬·장소), 게임 설정 카드 |
| `wishes.js` · `journal.js` | 소원 목록과 채움 규칙, 꿈 일지의 짝(채점/해석) |
| `bonds.js` · `people.js` | 인연 카드, 인물과 얼굴 |
| `house.js` | 집 단계와 물건 칸 |
| `interp.js` | 육관대사 문답, 해석 선택지, 근거 구절 |

## 만든 방법

- **설계**: 내용 설계서 `design/기획서_v1.md`(장면별 활동·물건·구슬·시간·에셋 목록), 원작 확인 `design/research/01_원작_검증노트.md`(판본 계열, 장면 순서, 소원의 근거, 이본 차이, 출처).
- **그림**: Codex CLI의 이미지 생성으로 만든 **도트(픽셀) 그림**입니다. 인물 설정 그림(`design/ref/`)을 먼저 만들어 장면·초상·말이 같은 얼굴과 옷을 유지하게 했습니다. 그림마다 32색 이하로 줄이고 무손실 webp로 저장했으며, 화면에서는 정수 배율로만 키웁니다. 장면 27장(480×270), 초상 51장, 말판 위 말의 걷기·뛰기 시트 4장(옷차림별), 집 4단계, 물건 14개, 구슬, 화면 장식이 있습니다. 프롬프트 `tools/make_prompts.py`, 생성 `tools/gen.ps1`·`tools/genqueue.ps1`, 가공 `tools/process_assets.py`·`tools/process_sprites.py`, 점검 `tools/check_assets.py`. 생성 원본(`assets/raw/`)은 저장소에 올리지 않습니다.
- **배경음**: 국립국악원 「디지털 이음」의 국악기 연주 악구(**공공누리 제1유형·출처표시**)를 이어 붙여 18곡을 만들었습니다(`assets/bgm/`). 정경패 장면은 거문고 실제 연주입니다. 「디지털 이음」에 퉁소 녹음이 없어, 퉁소 곡(난양공주의 달밤, 취미궁)은 같은 세로로 부는 대나무 관악기인 **단소** 「청성곡」 연주로 대신했습니다. 곡마다 쓴 악구 번호는 `js/data/bgm.js`에 있고, 다시 만들기는 `python tools/make_bgm.py`(원음은 `tools/music_src/`, 저장소에 올리지 않음)입니다. 효과음은 브라우저에서 합성합니다. 파일을 못 불러오면 합성한 가락으로 대신합니다.
- **글꼴**: 제목·단추·말판 이름은 갈무리(도트 글꼴), 본문·한자는 Noto Serif KR. 게임에 쓰인 글자만 남긴 부분 글꼴입니다(SIL OFL 1.1, `assets/fonts/OFL.txt`).
- **코드**: HTML + CSS + 순수 JavaScript(빌드 도구 없음). 엔진 `js/core/`, 화면 `js/game/`(말판·집·구슬·꿈 일지·깨어남·해석·결과).
- **테스트**(`tests/`, `npm install` 뒤 설치된 크롬으로): `node run-all.mjs`가 아래를 모두 돌립니다. 각 점검이 무엇을 확인하는지는 `run-all.mjs` 첫머리에 정리돼 있습니다.
  - `check-engine.mjs`: 장 진행, 이어 하기, 깨어난 뒤 잠금, 도움 사다리와 장부, 읽기 방식, 설정, 선생님용, 파일로 열기
  - `check-dream.mjs`: 말판, 소원 목록(미색은 '?'), 집 배치, 구슬, 깨어남, 꿈 일지, 해석 고치기, 결과 이미지
  - `check-content.mjs`: 실제 데이터 점검 + **학생처럼 끝까지 하기**(휴대폰·태블릿·데스크톱, 처음/다시 읽기, 일부러 틀리기, 중간 새로 고침, 깨어난 뒤 돌아가기 시도, 결과 이미지 저장, 알림이 글을 가리지 않는지, 글자 대비)
  - `check-assets.mjs`: 쓰는 그림이 모두 있는지, 정수 배율로 보이는지
  - `check-bgm.mjs`: 배경음 파일·음량(-20 LUFS ±2)·출처
  - `check-rights.mjs`: 저장소와 이력에 교과서 파일·문장이 없는지

## 음원 출처

이 게임의 배경음은 국립국악원이 공공누리 제1유형(출처표시)으로 개방한 「디지털 이음」 국악기 연주 음원(악구)을 이용했으며, 해당 저작물은 국립국악원 누리집(https://www.gugak.go.kr/digitaleum/)에서 내려받을 수 있습니다. 게임에서는 악구를 이어 붙이고 음량을 맞췄습니다(쓴 악구 번호는 `js/data/bgm.js`). 퉁소 곡은 퉁소 녹음이 없어 단소 연주로 대신했습니다. 게임 타이틀과 설정 화면에도 출처를 적었습니다.

## 알려진 한계

- **原文 대조 대기**: 한문 회목 16개와 핵심 구절은 아직 영인본 이미지와 맞대어 보지 못해 原文 표시를 붙이지 않았습니다. 국립중앙도서관 소장 계해본(1803) 영인 이미지는 전용 뷰어가 있어야 볼 수 있습니다. 대조하면 `js/data/scenes.js`의 회목에 원문을 넣고 상태를 바꾸면 됩니다.
- 작품 세부는 판본마다 다릅니다(을사본 한문 계열과 완판 한글본 등). 정답 판정은 공통 사실만 썼지만, 쓰시는 교과서 본문과 한 번 대조해 주세요.
- 장면 그림은 480×270 도트 그림이라, 좁은 휴대폰에서는 정수 배율 때문에 화면 폭보다 작게 보일 수 있습니다.
- 도트 인물은 AI가 그린 그림을 줄인 것이라, 여인들의 얼굴이 비슷한 그림체 안에서만 구별됩니다. 그림의 작은 어긋남(구경하는 승려의 머리, 봉래전 양소유의 관모 등)이 몇 군데 있습니다.
- 말판 위 말은 높이 28픽셀의 작은 도트라 걷는 모습이 단순합니다.
