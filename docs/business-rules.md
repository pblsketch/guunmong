# 게임 규칙

학생이 원작의 공간을 걷고 대화·관찰·물건 상호작용으로 성진과 양소유의 생애를 따라가는 체험 게임이다. 쌓은 것이 꿈이었음을 겪고 자신의 해석을 돌아보는 것이 목적이다. 새 플레이에 성장 점수·등급·능력 상승을 넣지 않는다. 소원 찾기와 맞대기의 정오답은 학습 증거로 유지한다.

## 설계 원칙과 장

- 시작은 c1-bridge 돌다리이며 돌아온 다음 선방을 방문한다. 기존 28단위·12사건·3이음·결말·벼슬·집 단계와 진행 id를 유지한다. 본편은 1→2→3→4→5→결과로 열린다. 조신은 결과에서 고르는 비교 자료다.
- 선택은 원작 상황을 이해하는 참여와 탐색 순서에 한정한다. 미래 사건·다른 마음·분기 결말을 고르지 않는다.
- 동선·공간 배치·상호작용 표현은 게임 연출이다. 작품과 무관한 리듬·카드 대결·전투 승패·HP·사냥·레벨·장비 효율·시간 제한·게임 오버·감점을 넣지 않는다.
- 가춘운·적경홍의 속임수는 원작대로 겪는다. 미리 간파·회피하지 않으며 난양공주를 혼례 전에 직접 만나지 않는다. 출정과 남해 태자 사건의 결과도 고정한다.
- 35~45분은 수업 설계 목표이며 실측값이 아니다. 풀이·얼굴·장 안내를 유지하며 처음/다시 읽기 방식 선택은 없다. 마친 장면의 다시 보기와 혼동하지 않는다.

## 체험과 원작 사실

필수 행동은 beats 순서대로 수행하며 optional 관찰은 완료 조건에서 제외한다. 공개된 대상의 인접 보행 칸에서 대화·관찰·사용·출구 행동을 수행한다. 한 사건의 시험장→한림원, 옥→위교 이동은 같은 scene 기록을 잇고 새 map/spawn의 안전 입구로 전환한다. 첫 선방과 마지막 선방은 map-cell을 공유한다.

행동 사실·물건·인연·구슬은 같은 저장에서 한 번 확정하고 연출은 성공 뒤에 한다. 필수 행동을 마친 뒤 사건 완료와 다음 pos를 함께 저장한다. readonly·다른 탭·이전 run은 기록을 만들지 않는다. 옛 준비·윤목·등급·능력·재화·최고값은 보존하며 새 수행이나 소원으로 추정하지 않는다. 옛 완료나 자동 안내를 새 actions로 만들지 않는다.

인물의 공적인 관계와 옷·호칭·열리는 공간은 이야기 위치에 맞춰 드러난다. 미래 인물·숨은 정체를 배경·호칭·초상·대상 목록·자산 이름으로 먼저 공개하지 않는다.

## 소원과 생활 공간

소원 다섯은 연화봉 독백에서 찾는다. 꿈속 채움은 저장된 다음 원작 사실만 사용한다. 입장만 한 현재 사건은 근거가 아니다.

| 소원 | 근거 |
| --- | --- |
| 출장입상 | e08-wonsu:appointment의 정서대원수, e11-seungsang:appointment의 대승상 각각 한 부분 |
| 부귀 | e12에서 받은 it-girinpo의 기린 도포·옥대 |
| 풍류 | l-namjeon에서 받은 it-geomungo와 it-tungso |
| 공명 | e11-seungsang:portrait의 기린각 초상 |
| 미색 | 꿈 내내 ?; c4-journal의 인연 잇기에서만 공개 |

내부 fill은 API 호환용이며 학생에게 퍼센트·합계로 보이지 않는다. 옛 done 또는 auto가 아닌 확정 grade는 해당 완료 사건의 원작 사실 근거로 인정하며 이미 보유한 원작 물건도 인정한다. 이것을 새 수행으로 만들지 않는다. auto는 학생 완료와 다르다. 인연은 소원 입력이 아니다.

객사·초가 → 정 사도 댁 별당 → 승상부 → 취미궁은 이야기로 정한다. 승상부는 대승상 임명 사실이 확정된 뒤에 열리며 사건 입장만으로 열지 않는다. 옛 실제 완료 기록도 해당 임명의 근거로 인정한다. 재화 투자·직접 배치·효율을 넣지 않는다. 물건은 뒤 사건과 일지에서 근거로 연결하며 인연을 꾸밈 물건으로 놓지 않는다. 말판 탭은 새 플레이에서 없애고 G.dream 공통 기능은 독립시킨다.

## 인연과 구슬

여덟 인연은 각자의 뜻으로 만난 인물이다. 최초 만남의 행동 사실에 카드를 연결하며 개수·점수·호감도·등급·소원 채움·획득 축하를 붙이지 않는다. 구슬과 인연은 서로 다른 기록이다.

첫 만남 여덟 곳의 구슬 찾기는 선택이다. 놓쳐도 진행·평가에 불이익이 없다. 새 지도에 정수 좌표를 명시하고 실제로 닿고 누를 수 있게 한다. 카메라 이동 또는 대상 목록으로 화면 밖 대상도 접근한다. 옛 그림 좌표를 그대로 써서 잘림·가림을 숨기지 않는다.

정경패 명주는 한문 계열 근거이며 완판 대조는 미확인이다. 난양공주의 탄생 꿈은 두 계열 근거다. 나머지 여섯은 게임 설정이다. 구슬은 채점하지 않으며 이본 단독 사실을 공통 정답으로 쓰지 않는다.

## 채점·도움·장부

채점 활동은 소원 찾기와 맞대기 둘뿐이다. 인연 잇기·구슬·해석은 채점하지 않는다.

- 소원 찾기는 바람을 나타내는 낱말 다섯을 모두 찾아야 진행한다. 오답이 없으면 첫 시도 맞힘, 오답 뒤 완료는 다시 풀어 맞힘이다. 두 번째 오답 뒤 메모와 정답 도움으로 연결한다. 독백에 분명한 다른 바람을 오답으로 쓰지 않는다.
- 맞대기는 다섯 칸을 채운 뒤 함께 확정하며 소원 넷을 여러 칸에 재사용한다. 오답 표시→메모→정답 보기의 도움을 유지한다.
- 첫 시도는 불변이다. 선생님 도움이 먼저면 first:null, teacher 도움은 student로 내려가지 않으며 final 뒤 장부는 불변이다.
- 사건 12행은 미시작/진행/완료/자동 안내/이전 기록, 살펴본 행동 근거와 도움 여부를 보여 준다. 옛 등급이나 완료만 있고 새 행동을 수행하지 않은 사건은 이전 기록으로 구분한다. 활동 둘과 장부 14행을 유지하며 옛 적중·등급·수치를 새 수행 결과로 표시하지 않는다. 구슬은 점수가 아니다.

정답은 을사본 한문 계열과 한글 완판본의 공통 사실만 쓴다. 양류사의 글자·곡명·꽃잎 수·염주·조신의 햇수·삭발 세부·하북 특정 직함 등 이본 차이는 정답으로 묻지 않는다. 장주의 나비는 해석 근거로만 쓴다.

## 깨어남과 다시 열기

들어 올린 지팡이는 입력 전 멈춘다. 난간 타격 입력 순간 app.wake가 현재 writer·run·접근 권한을 검사하고 행동 사실·awake/awakeAt·선방 pos를 동기 저장한다. 성공 뒤에만 타격과 공간이 걷히는 연출을 시작한다. 거부·실패 때는 기존 상태와 올린 자세를 지킨다. 입력 전 생략은 없고 staff는 일반 apply/finish로 마칠 수 없다. 점수 폭발·점수→0 연출은 없다.

깨어난 학생은 빈 선방 앞의 0~3장을 주소·목차·뒤로·새로 고침·출구·꿈 도구·bfcache·설정의 옛 단추로 열지 못한다. 선생님용만 예외이며 되돌리는 길은 확인 초기화뿐이다. e10의 작은 꿈은 백룡담에서 진영으로 돌아오며 awake를 쓰지 않는다. 마지막 선방은 처음과 같은 벽·방석·출입구이며 꿈의 도구·출구를 제거하고 성진의 짧은 이동·관찰만 허용한다. 허무의 정답을 강요하지 않는다.

| 종료 위치 | 재개 |
| --- | --- |
| 보행 도중 | 마지막으로 저장한 유효 칸 |
| 행동 확정 뒤 | 현재 scene/beat가 허용하는 지도, 사실·최초 수행자 보존 |
| 옛 부분 준비 | 현재 체험의 안전 입구, turns/rolls 보존 |
| 완료와 다음 pos 사이 | 다음 미완료 단위 |
| 일반 컷신 | 해당 컷신 처음 |
| 깨어남 전 3장 | 취미궁부터 연출 재연, 이미 남긴 사실은 보존 |
| 난간 타격 이후 | 빈 선방 이후 |

직접 다시 보기는 readonly다. auto의 순차 재생은 자동 안내를 보존하고 다음 pos만 옮긴다. 과거 auto·부분 기록을 새 학생 완료로 바꾸지 않는다.

## 꿈 일지와 해석

일지의 다섯 짝은 장수·재상→출장입상, 도포·옥대→부귀, 도인의 두 악기→풍류, 기린각 초상→공명이다. 인연 잇기는 어느 선택이든 미색을 드러내며 찾은 구슬은 팔선녀 카드로, 놓친 것은 흐리게 남긴다.

해석은 응답 전에 선택지 네 개와 근거 하나를 고른다. 근거 열 개 중 after:true 세 개는 응답 뒤에 공개한다. 첫 선택은 응답 진입 전에 잠기고 재접속으로 바꾸지 않는다. 응답 후 한 번 수정·확정하면 불변이며 같은 내용 확정은 수정 흔적 없음이다. 출가 컷신이 결말을 잇는다.

맞대기의 일부 오답만 저장된 뒤 실패하면 재시도에서 이미 남은 첫 오답을 중복 추가하지 않는다. 해석 확인 뒤에는 선택을 동결하며 마지막 저장 실패 때에도 확정한 선택으로 재시도한다.

결과 DOM과 PNG는 이름·날짜·질문·최종 해석·근거·수정 흔적·소원·구슬·도움 안내와 취미궁/선방 대비를 같은 모델에서 그린다. PNG는 저장 버튼을 누른 시점의 결과를 사용한다. 화면에 남은 이름의 저장이 실패하면 내보내지 않으며, 대기 중 화면 이탈이나 초기화가 발생하면 늦은 다운로드를 취소한다. 사라진 꿈 도구를 결과에서 재개하지 않는다.

## 선생님용·단일 저장 탭·초기화

선생님용은 모든 장을 열 수 있으나 reader에서는 설정도 저장하지 않는다. 바로가기는 미완료 앞 사건의 안내만 만들며 부분·완료·auto를 덮어쓰지 않는다. 도움 수행자는 남기고 학생 도움으로 내리지 않는다. 선생님용을 끄면 열린 월드·대화·도구·옛 단추에도 현재 권한을 즉시 적용하고 허용된 일지·해석 입력은 보존한다.

같은 저장 열쇠에 Web Locks writer 한 탭만 둔다. acquiring/writer/reader/unavailable를 구분하고 권한 전에는 진행 입력을 열지 않는다. reader의 이어 하기는 권한을 다시 요청해 최신 기록을 읽고 재개한다. 지원·요청 실패는 unavailable이며 타이머 임대·새 열쇠·steal로 우회하지 않는다.

pagehide는 즉시 쓰기를 막고 권한을 해제한다. bfcache 복귀와 권한 이전은 최신 run·awake·해석을 다시 읽는다. reader의 storage 변화는 이전 화면을 폐기하며 입력을 새 회차에 옮기지 않는다. 화면·비동기 콜백은 시작한 run을 보존한다.

확인 초기화는 화면·이동·대기·모달을 먼저 취소하고 music/sound/big/teacher만 남긴 새 run과 awake:false를 한 번 저장한다. 실패하면 옛 상태 객체·run·기록을 유지한다. 이전 콜백은 stale로 거부하고 같은 run의 awake와 최초 awakeAt은 되돌리지 않는다. v1은 읽거나 지우지 않는다. 기록은 기기 밖으로 보내지 않는다.

## 글과 原文

이야기는 G.storyText 기준 한글 음절 4,400 이하다. 새 월드가 참조한 본문·소원 독백·대사·서술·컷신·대사의 응답·결말을 포함하며 본문은 복사하지 않는다. 아직 남아 있는 구판 등급 문구도 총량에서 임의로 빼지 않는다. 예고·노트·인연 카드·선택지·단추는 제외한다.

풀이와 대사는 새로 쓴다. 原文 낙관은 영인 대조를 마친 한문 회목·핵심 구절에만 붙인다. 지금 대조 완료 글은 없으며 전사본의 의심 글자를 임의 확정하지 않는다.
