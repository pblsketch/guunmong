# 보안·개인 정보·권리

이 게임에는 서버·계정·로그인이 없다. 지켜야 할 것은 세 가지다: 학생 기록이 기기 밖으로 나가지 않는 것, 공개 저장소에 들어가서는 안 되는 이름·교과서 자료가 들어가지 않는 것, 게임에 쓰는 모든 자산을 상업적으로 쓸 수 있는 것.

## 지키는 것

| 지킬 대상 | 무엇이 문제인가 | 어디에 있나 |
| --- | --- | --- |
| 학생 기록 | 진행·행동·위치·물건·장부·오답·해석·이름, 고른 말·첫 판가름·숨긴 소원·가장 찼던 소원. 학생이 쓴 이름은 개인 정보다 | 그 브라우저의 localStorage(`guunmong-v3`)뿐. 이전 판의 `guunmong-v2`·`v1`은 고치거나 지우지 않는다(v3가 없을 때 v2의 설정 넷만 읽음) |
| 결과 PNG | 이름·날짜·해석이 그려진 그림 | 학생이 [이 장을 그림으로 저장]을 눌러 직접 내려받을 때만 생긴다 |
| 교과서 출판사 이름과 교사 자료 사이트 이름 | 계약 전 공개 저장소에 드러나면 안 된다 | 이 기기의 기획 문서 폴더(`.gitignore`의 첫 항목)와 교과서 자료 폴더(`design/source/`)에만 |
| 교과서 자료 | 교과서·지도서·연구용 교과서·학습지·활동지·PPT 파일과 본문 추출본. 저작물이다 | `design/source/`에만. 장면 범위와 판본을 대조하는 데에만 쓴다 |
| 자산 사용권 | 상업 이용이 안 되는 그림·소리·글꼴이 들어가면 시리즈 제안 자체가 막힌다 | `assets/` |
| 이 기기의 Codex 자격 증명 | 그림 생성 도구가 `~/.codex/auth.json`을 복사해 쓴다 | 생성하는 동안만 `%TEMP%\codex-img-guun-<그림 이름>\auth.json`(끝나면 지움) |

## 접근 모델

로그인이 없으므로 '누가'는 기기를 쥔 사람 하나다. 선생님용은 보안 장치가 아니라 수업 편의 기능이고, 주소에 `?teacher=1`을 붙이면 누구나 켤 수 있다. 그래서 선생님용이 하는 일은 모두 기록으로 드러나게 한다.

| 주체 | 할 수 있는 것 | 할 수 없는 것 |
| --- | --- | --- |
| 학생(writer) | 열린 장과 마친 장면 열기, 활동 풀기, 기록 남기기, 이름 쓰기, 결과 PNG 저장, 기록 전체 지우기(확인 후) | 열리지 않은 장 열기, 깨어난 뒤 꿈 장 열기, 마친 활동의 장부 바꾸기, 기록 일부만 지우기 |
| 선생님용(writer, 누구나 켤 수 있음) | 모든 장 열기, 정답 채우기·보기, 기록 없는 앞 장면의 자동 안내, 깨어난 뒤 꿈 도구 보기 | 흔적 없이 정답 채우기(장부에 '도움 사용(선생님용)'으로 남음), 다른 기기의 기록 보기 |
| reader·권한 확보 전·권한 실패 탭 | 허용된 기록 열람, 명시적 저장 권한 재요청 | 진행·행동·답·이름·설정·초기화 저장, 저장 상태의 메모리 변경 |
| 게임 코드 | 같은 출처의 정적 파일 읽기, localStorage 읽고 쓰기, 학생이 누를 때 PNG 내려받기 | 바깥 주소로 요청 보내기, 분석·추적 도구 싣기, 바깥 글꼴·CDN 불러오기, 이름을 외부로 자동 전송하기 |

같은 저장 열쇠에는 Web Locks의 배타 writer 한 탭만 둔다. 저장은 현재 회차를 확인한 뒤 수행하고 다른 탭은 읽기 전용이다. 권한을 넘겨받을 때와 bfcache 복귀 때 최신 기록을 다시 읽으며, 이전 회차의 콜백은 쓰지 못한다. 잠금 API 부재·요청 실패는 저장 불가 안내로 처리하고 마지막 저장 우선이나 타이머 잠금으로 우회하지 않는다.

- 같은 기기의 다른 사람이 같은 브라우저를 열면 앞 사람의 기록이 보인다. 공용 기기에서는 끝난 뒤 설정 → 기록 지우기를 쓰도록 교사가 안내한다. 게임이 사람을 구분하지는 않는다.
- 주소 인자는 이름 같은 개인 정보를 담지 않는다. 결과 PNG 파일 이름에만 이름이 들어간다(파일 이름에 못 쓰는 글자는 뺀다).

## 기록되는 것

서버가 없으므로 감사 기록은 학생 기기의 상태 안에만 있다. 교사가 디브리핑에서 확인할 수 있는 것은 다음뿐이다.

- 소원 찾기·맞대기의 첫 시도와 도움 사용, 사건의 행동·최초 수행자·도움과 완료 상태.
- 자동 안내는 실제 학생 수행과 구분한다. 선생님용·바로가기로 넘긴 대목은 학생의 선택·첫 판가름으로 기록하지 않는다.
- 고른 말·첫 판가름·숨긴 소원은 결과 화면과 5장 되짚기에만 쓰고 채점·장부·외부 전송에 쓰지 않는다.
- 깨어난 시각(`awakeAt`), 시작 시각, 결과에 처음 닿은 시각.
- 해석을 고친 흔적(처음 고른 것과 고친 것).

구판 v1은 새 판에서 읽거나 지우지 않는다. 전체 진행 초기화는 확인 뒤 현재 화면·대기를 먼저 취소하고 v2의 설정 네 개만 남긴 새 회차를 한 번 저장한다. 실패하면 옛 상태·회차·저장 원문을 보존한다. 같은 회차의 깨어남과 최초 시각은 되돌리지 않는다.

학생 기록을 모으는 장치(학급 관리, 결과 전송)는 없다. 결과는 학생이 PNG를 직접 내거나 화면을 보여 주는 방식으로만 교사에게 간다.

## 권리 규칙

1. **금지된 두 이름**: 교과서 출판사 이름과 교사 자료 사이트 이름은 git이 추적하는 어떤 파일에도(그림·소리·글꼴 같은 바이너리 안에 박힌 글자까지), 어떤 커밋의 내용과 커밋 글에도 없어야 한다. 교과 연계는 "공통국어2 「구운몽」 단원"처럼 과목·단원으로만 적고, 공개 설계 문서에서는 '교과서'라고만 쓴다. 이 이름을 확인하는 점검 코드조차 이름을 글자 번호로 만들어 파일에 글자로 남기지 않는다.
2. **교과서 파일**: `design/source/`의 파일과 같은 이름의 파일, 이름에 교과서·지도서·학습지·활동지·제재 정리·작가 소개·단원·공통국어가 든 hwp·hwpx·ppt·pptx·pdf는 어느 이력에도 올라가면 안 된다.
3. **교과서 문장**: 공백·문장부호를 뺀 글자로 쟀을 때 교과서 본문과 15자 이상 이어서 같은 글이 추적 파일에 있으면 안 된다. 게임 글·README·설계 문서·코드 주석 모두 해당한다. 원작의 줄거리와 사실은 새 문장으로 쓴다.
4. **기획 문서**: 기획 문서 폴더(`.gitignore`의 첫 항목)는 어느 이력에도 올라간 적이 없어야 한다. `.gitignore`가 이 폴더와 `design/source/`를 빼고 있어야 한다.
5. **자산 사용권**
   - 그림: 사용자 검토를 거쳐 승인된 Codex CLI 및 내장 image_gen 생성 그림을 쓴다. 현재 승인 이력은 두 경로를 포함한다. 제품 해시·원본·실제 프롬프트·이전 후보를 보존하고, 재생성·교체는 새 승인을 받는다. 다른 게임·웹의 그림을 가져오지 않는다.
   - 배경음: 국립국악원 「디지털 이음」 악구(공공누리 제1유형: 상업 이용·편집 가능, **출처 표시 필수**)만 쓴다. 출처는 타이틀, 설정, README 세 곳에 보이고, 곡마다 쓴 악구 번호를 데이터에 남긴다. 효과음과 대체 가락은 브라우저 합성이다.
   - 글꼴: SIL OFL 1.1 글꼴(갈무리, Noto Serif KR)만 쓰고, 부분 글꼴은 원래 이름을 쓰지 않고 `Guun…`으로 바꾸며, `assets/fonts/OFL.txt`를 함께 배포한다.
   - 대사 목소리: Fish Audio 유료 API(크레딧 결제 계정)로 미리 만든 음성(`assets/voice/`). 2026-10-08 사용자가 상업 이용 가능을 확인했다(결정 0024). 목소리 모델과 화자 배정은 `tools/tts_voices.json`에 남긴다. 게임은 실행 중 바깥 API를 부르지 않는다.
   - 사용권이 확인되지 않은 자산은 넣지 않는다.

## 공개

- 공개 주소는 https://pblsketch.github.io/guunmong/ 이다. 2026-10-05 사용자 배포 지시에 따라 검증한 추적 파일만 기존 공개 저장소에 반영했다. 작업 저장소의 이력과 무시된 원본·검증 기록은 올리지 않았다. 공개 런타임 231개의 원본 내용과 Chrome 학생 도입·저장·재접속·두 탭 권한 이전을 확인했다.
- 공개 위치는 pblsketch 계정의 GitHub Pages다. 저장소 만들기, 올리기, Pages 켜기는 그때마다 사용자의 확인을 받는다.
- 작업 저장소의 이력은 그대로 올리지 않는다. 지금 추적 파일은 권리 점검을 통과하지만, 예전 커밋에는 교과서 문장과 겹치던 설계 문서 글이 남아 있다(겹침 점검은 지금 파일만 본다). 공개는 지금 추적 파일만 이력 없이 새 저장소의 첫 커밋으로 옮긴 깨끗한 내보내기로 한다.
- 내보낸 저장소에서도 권리 점검을 돌려 통과해야 올린다.

## 자격 증명

- 이 프로젝트의 코드와 데이터에는 비밀번호·키·토큰이 없고, 있어서도 안 된다.
- 그림 생성 도구(`tools/gen.ps1`)는 Codex의 전역 설정을 피하려고 그림마다 임시 폴더를 `CODEX_HOME`으로 만들고 `~/.codex/auth.json`을 복사해 넣는다. 생성이 끝나면 `gen.ps1`이 이 복사본을 지운다(2026-10-03 전에 남은 폴더는 그날 모두 지움). 생성이 중간에 끊겼다면 `%TEMP%\codex-img-guun-*` 폴더에 복사본이 남을 수 있으니 지운다. 이 폴더를 저장소 안이나 공유 위치로 옮기지 않는다.
- 교사 자료 사이트 로그인, 비밀번호 입력, 국악원 내려받기 양식 제출은 언제나 사용자가 직접 한다.
