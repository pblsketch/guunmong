# 0023. 임무 카드 세 장, 어디서든 길 따라가기, 숨긴 조작 도구

2026-10-08.

## 맥락

0022를 반영한 판을 사용자가 직접 해 보고 세 가지를 지적했다.

- 오른쪽 아래 '조작 도구' 단추는 없어도 된다. 두 손 조작(왼쪽 끌기·오른쪽 행동 단추)과 느낌표로 이미 충분하다.
- 새 공간으로 넘어갈 때 비석처럼 생긴 길 표시까지 되돌아가 '길 따라가기'를 누르는 방식이 어색하다.
- 임무가 게임의 중심인데, 첫 장면에서 학생이 자기 역할과 몰입해야 하는 까닭을 자연스럽게 알기에는 긴 설명 창이 부족하다.

## 결정

- **임무 카드.** 새로 시작하면 돌다리 그림이 비치는 어두운 막 위에 카드 세 장을 한 장씩 넘긴다. ① 역할: "당신은 오늘 성진입니다" ② 할 일: 꿈속 한평생을 살며 위기마다 판단하고 고른 말로 소원을 채운다(위 소원 막대가 내가 산 삶) ③ 까닭: 깨어나면 스승이 "그 삶은 처음 바라던 삶과 같았느냐?"고 묻고 내가 고른 길이 답의 근거가 되며, 꿈 일지가 수업의 결과물이 된다. 마지막 카드에서만 시작 단추가 나온다. 기록을 쓰지 않고 이야기 지도에서 다시 볼 수 있다.
- **길 따라가기.** 다른 장소로 가는 길은 비석 그림 대신 땅 위에서 빛나는 자리로 그린다. 그 장면의 필수 행동을 마쳐 길 차례가 되면 학생이 어디에 있든 행동 단추가 "길 따라가기"를 보이고, 누르면 인물이 길까지 걸어가 넘어간다. 행동 기록과 순서 검사는 그대로다(길에 닿은 뒤 같은 행동으로 기록).
- **조작 도구 숨김.** 대상 목록·조작 안내·방향 버튼을 담은 패널은 화면에서 숨긴다. 키보드 Tab 초점이 닿거나 열었을 때만 보여, 화면 낭독기·키보드 사용자가 대상으로 가는 길은 남긴다.

## 다른 길

- **패널을 완전히 지우기**: 화면 낭독기·키보드 사용자가 화면 밖 대상으로 갈 길이 없어진다.
- **필수 행동을 마치면 자동으로 다음 장면**: 선택 구슬 찾기 같은 탐색을 끝내기 전에 넘어가 버린다.
- **길 칸에 닿기만 하면 넘어가기**: 여전히 길까지 걸어가야 하고, 실수로 밟아 넘어갈 수 있다.
- **임무를 육관대사의 대사로 지어 넣기**: 원작에 없는 장면을 만드는 셈이라, 게임이 학생에게 직접 말하는 카드로 했다.

## 결과

- 0020의 임무 창(긴 글 하나)을 카드 세 장으로 바꾼다. 이야기 지도의 임무 다시 보기는 세 카드를 목록으로 보인다.
- 터치 사용자는 조작 도구 패널을 열 수 없다. 방향 버튼은 키보드로 패널을 연 경우에만 쓴다.
- 비석 모양 길 그림(prop-path)은 자산으로 남지만 화면에 그리지 않는다. 저승 출입구·백룡담 물길처럼 원작 물건인 길은 그대로 그린다.
