# 0006. 화풍: 네 시안 가운데 도트(픽셀)

## 맥락
그림은 Codex CLI 이미지 생성으로 만든다. 같은 장면을 병풍 채색, 목판, 도트, 수묵·채색 대비의 네 시안으로 만들어 사용자가 직접 보고 골랐다(`design/style-samples/`).

## 결정
도트 화풍(시안 C, `style_c_pixel.jpg`)으로 간다. 그림마다 32색 이하로 줄이고 무손실 webp로 저장하며, 화면에서는 기기 픽셀 기준 정수배로만 키운다. 인물 설정 그림을 먼저 만들어 장면·초상·말이 같은 얼굴과 옷을 유지하게 한다.

## 다른 길
- **병풍 채색**: 고전 분위기는 가장 강하지만 생성 그림마다 붓질·색감이 달라 129장의 일관성을 맞추기 어렵고, 작은 휴대폰 화면에서 세부가 뭉갠다.
- **목판**: 일관성은 좋지만 단색 위주라 장면과 인물의 구별이 약하다.
- **수묵·채색 대비(현실은 수묵, 꿈은 채색)**: 꿈과 현실의 대비는 선명하지만 두 화풍을 모두 일관되게 생성해야 한다. 이 대비는 도트 안에서 현실 장면의 채도를 낮추는 것으로 대신했다.

## 결과
- 도트 그림은 자르고 줄이고 색을 줄이는 가공 파이프라인(`tools/pixlib.py`)을 거친다. 아주 작은 그림(구슬)은 생성하지 않고 코드로 찍는다.
- 정수배 표시 때문에 좁은 휴대폰에서 장면이 화면 폭보다 작게 보일 수 있다.
- 다른 화풍으로 바꾸려면 사용 중인 도트 자산 전체의 일관성을 다시 맞춰야 한다.
