# 0014. 서버 없이 브라우저에만 저장하고, 결과는 PNG로 낸다

## 맥락
교사는 학생 결과를 보고 디브리핑하고 싶다. 결과를 모으려면 서버·계정·학급 관리가 필요하지만, 그러면 개인 정보 처리와 운영 부담이 생기고 시연작의 범위를 넘는다. 교실 기기는 휴대폰부터 PC까지 제각각이다.

## 결정
설치·로그인·서버가 없는 정적 웹 게임으로 만들고, 진행은 그 브라우저의 localStorage에만 저장한다. 결과는 학생이 꿈 일지 마지막 장을 PNG로 내려받아 내거나 화면을 보여 주는 방식으로 교사에게 간다. 분석 도구를 넣지 않는다. `index.html`을 파일로 열어도 동작하게 한다.

## 다른 길
- **결과 전송 서버와 학급 코드**: 교사가 한눈에 모아 보지만 개인 정보 동의·보관·삭제 절차가 필요하고, 학교 망에서 막힐 수 있다.
- **구글 폼 같은 바깥 서비스로 결과 보내기**: 서버는 없지만 학생 기록이 제3자에게 가고, 바깥 주소가 바뀌면 깨진다.

## 결과
- 한 기기 한 사람이 전제다. 탭 두 개로 열면 나중에 저장한 쪽이 남고 따로 막지 않는다.
- 같은 브라우저를 다른 학생이 쓰면 앞 기록이 보이므로 공용 기기에서는 기록 지우기를 안내한다.
- 교사가 여러 학생의 장부를 한 화면에서 모아 볼 수 없다.
- 정적 파일이라 GitHub Pages가 아닌 다른 사이트(계약 뒤 출판사 사이트 등)로 그대로 옮길 수 있다.
