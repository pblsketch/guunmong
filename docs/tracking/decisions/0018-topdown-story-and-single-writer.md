# 0018. 원작 공간의 체험과 한 탭 저장

2026-10-05.

## 맥락

같은 준비 선택과 긴 글을 반복하는 구조에서 성진의 동경과 양소유의 삶을 직접 느끼기 어렵다는 판단이 있었다. 학생이 인물에게 다가가고 원작의 물건과 상황을 살피도록 바꾸면서, 깨어난 뒤의 기록을 다른 탭이나 오래된 화면이 되돌리지 못하게 해야 했다. 휴대폰에서 그림 아래 문서를 길게 읽는 방식도 게임 안에서 모든 진행을 이어 가는 화면으로 바꾸기로 했다.

## 결정

탑다운 공간에서 걷기·관찰·대화·물건 행동을 수행한다. 본편의 28단위·12사건·3이음·결말과 진행 식별자는 유지한다. 선택은 원작 상황 안의 탐색 순서이며 새 전투·육성·분기 결말을 만들지 않는다.

준비 두 턴·윤목·능력 상승·성공 등급·성장 점수·재화에 따른 집 꾸밈을 새 플레이에서 사용하지 않는다. 신분과 삶의 변화는 옷·생활 공간·원작 물건·주변 반응으로 드러낸다. 인연은 수집 수치나 소원 채움의 입력이 아니다. 소원 찾기와 맞대기의 첫 시도·도움·정오답은 학습 기록으로 유지한다.

필드는 게임 화면을 채우고 대화·소원·책·결과·설정은 같은 화면 안에서 진행한다. 긴 내용은 대사 페이지 또는 책 창 안의 접근 가능한 스크롤로 읽는다. 휴대폰은 세로를 기본으로 두되 가로에서도 일반·큰 글자를 지원하고 방향을 강제로 잠그지 않는다.

같은 저장 열쇠의 writer는 Web Locks로 한 탭만 둔다. 다른 탭과 권한 확보 전·실패 상태는 기록을 쓰지 못한다. 현재 회차만 저장하며 권한 이전에는 최신 기록을 읽는다. 난간 타격은 행동과 깨어남·최초 시각·선방 위치를 먼저 함께 저장하고 성공 뒤에 연출한다. 확인 초기화만 기존 화면을 취소한 뒤 새 회차를 저장한다. 실패하면 이전 기록을 유지한다.

결과에는 취미궁과 처음부터 공유한 선방의 그림, 학생이 고른 해석 근거를 남긴다. 숫자가 0이 되는 연출은 사용하지 않는다. 화면과 900px PNG는 같은 결과 모델을 사용하며 사라진 꿈을 다시 여는 링크를 제공하지 않는다.

## 이전 결정에서 유지하거나 교체한 것

- 0015의 두 준비·적중 등급·수치 성장·점수 소실은 공간 체험과 꿈의 대비로 교체한다. 원작 순서·인연 분리·두 채점 활동·이전 학생 기록 보존은 유지한다.
- 0017의 돌다리 시작·선택형 조신 비교·기존 장 인덱스와 id 보존은 유지한다. 그림 아래 문서 전체 스크롤과 준비 단서 되짚기는 게임 내 대화·책 창과 원작 행동으로 교체한다.
- 0014의 서버 없는 브라우저 저장·수동 PNG 출력은 유지한다. 여러 탭에서 나중 저장이 남는 방식은 단일 저장 탭과 회차 검사로 교체한다.
- 과거 0001·0004·0013의 장르/활동 적용 설명은 당시 판의 이력이다. 새 플레이를 말판이나 준비 틀로 되돌리는 현재 규칙으로 사용하지 않는다.
- 0016의 96px 지팡이와 구판 준비 원본·이전 후보 보존은 유지한다. 새 32px 걷기·정지 NPC와 같은 축소 규격으로 취급하지 않는다.

## 다른 길

- 기존 준비 구조에 걷기만 덧붙이면 사건마다 같은 선택을 반복하는 문제와 수치 의존이 남는다.
- 원작을 자유 분기나 전투 승패로 바꾸면 사건·결말을 다른 이야기로 기억하게 한다.
- 지도 아래 긴 문서를 계속 붙이면 게임 공간과 읽기 영역이 갈라지고 휴대폰 화면의 흐름이 끊어진다.
- 마지막 저장 우선이나 시간 만료 잠금은 오래된 탭이 깨어남과 확정 기록을 덮는 경로를 남긴다. 별도 서버는 학생 기록을 기기 밖으로 보내지 않는 전제와 맞지 않는다.

## 결과

말판·준비·성장 계산 파일과 옛 능력·재화·등급 기록은 호환 자료로 보존하지만 새 수행을 만들어 내는 데 쓰지 않는다. 꿈 도구는 말판 파일 없이 초기화한다. 현재 규칙은 저장 권한을 얻을 수 없는 환경에서 저장 가능한 플레이를 열지 않는다. 그런 환경의 지원 여부를 실제 확인 없이 보장하지 않는다.

자동 완주와 화면 크기 검사는 조작·기록·출력의 증거다. 실제 학생의 몰입·35~45분, 실기기와 다른 브라우저, 공개 배포 결과는 따로 확인한다. 이 결정은 새 배포나 외부 전송의 승인이 아니다.
