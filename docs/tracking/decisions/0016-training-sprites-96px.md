# 0016. 준비와 지팡이 동작은 96px 셀로 보존한다

## 맥락

32px 셀로 줄인 준비 그림을 실제 표시 크기로 확대하니 눈·손·책이 뭉개졌다. 사용자가 품질을 지적했고, 같은 생성 원본의 32·64·96px를 같은 화면 크기로 비교했다.

## 결정

2026-10-03 사용자가 96×96을 선택했다. 준비 네 동작과 호승 지팡이는 96px 셀 네 프레임으로 가공한다. 아이콘은 32px, 말판의 기존 말은 32px 셀을 유지한다. 화면 목표 크기는 약 96 CSS px이며 기기 픽셀 기준 허용 배율을 적용한다.

## 다른 길

- 32px를 다시 확대하면 사라진 얼굴·소품 정보는 돌아오지 않는다.
- 64px도 비교했으나 96px가 작은 동작의 세부를 더 분명히 보존했다.
- 화풍을 바꾸거나 같은 원본을 무조건 재생성하는 대신, 보존된 원본의 정보를 살리는 재가공을 택했다.

## 결과

셀 크기를 32로 고정한 가공·렌더링을 준비 그림에 재사용할 수 없다. 메타의 width/height와 프레임 수를 사용하고 공통 배율·발 위치·팔레트를 검증한다. 32색·무손실·당나라 의복·그림에 글자 없음은 유지한다. 원본 프롬프트의 당시 표현과 이전 후보를 지우지 않으며, 새 그림 변경은 다시 검토하고 승인받는다.
