# 0005. 수능 연결 단계를 두지 않는다

## 맥락
처음 구상에는 결과 뒤에 처음 보는 같은 갈래 작품(예: 「옥루몽」)을 읽고 푸는 수능 연결 단계가 있었다. 한 차시 분량은 이미 43분 50초로 차 있다.

## 결정
수능 연결 단계는 만들지 않는다. 사용자가 명시적으로 뺐다. 「구운몽」 밖의 작품도 다루지 않는다.

## 다른 길
- **결과 뒤 선택 단계로 넣기**: 시험 대비 수요는 채우지만 한 차시를 넘기고, 게임의 마지막 감정(빈 선방, 대사의 물음, 자기 해석)이 문제 풀이로 끝나 버린다.
- **별도 화면으로 따로 열기**: 분량 문제는 피하지만 다른 작품의 原文·풀이·권리 확인이 따로 필요하다.

## 결과
- 결과 화면이 게임의 끝이다. 마무리는 생각 나눔 질문, 작품 노트, 교사의 디브리핑이 맡는다.
- 다른 작품은 시리즈의 다른 편에서 다룬다.
