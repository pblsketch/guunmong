## 현재 확인 범위

돌다리부터 결과까지 본편 28단위·12사건·3이음을 연결했다. 최종 검토 수정까지 반영한 코드 a1307bd의 전체 검사 10/10과 선생님용·진행 주입 없는 세 자동 완주를 확인했다. 독립 검토의 남은 지적은 0건이다. 실제 학생 관찰과 수업 시간 실측은 미실행이다. 도입 여섯 단위와 깨어남 네 단위의 별도 시험 주소도 유지하며 이 대표 시연만으로 본편 전체 완주를 대신하지 않는다. 원본 전체 로그는 tests/shots/run-all-2026-10-05T08-08-47-668Z.log다.

게임은 고정 화면의 필드를 직접 걷는 방식이다. 인물이나 물건을 누르면 가까이 이동하고, 도착한 뒤 다시 누르거나 Enter·Space로 행동한다. 도착만으로 사건을 완료하지 않는다. 대화는 필드 위 임시 창, 소원·책·결과·설정은 게임 안의 창에서 진행한다. 방향 버튼·대상 목록·도움은 접힌 조작 도구에 있다.

## 준비와 실행

1. 작업 폴더에서 `python -m http.server 8767 --bind 127.0.0.1`을 실행한다.
2. 전체 관찰은 `http://127.0.0.1:8767/`에서 일반 학생 모드로 처음부터 결과까지 진행한다. 기존 기록을 쓸 때는 관찰 목적을 구분하고, 새 판은 확인 초기화로 시작한다.
3. 빠른 부분 시연은 `?fixture=rpg-opening`(도입)과 `?fixture=rpg-waking`(깨어남)을 쓴다. 둘은 별도 시험 기록이다. 깨어남 시연은 앞의 삶을 생략했다는 맥락을 알리고 이를 학생의 새 수행으로 세지 않는다.
4. 휴대폰 세로 화면과 PC 키보드부터 확인하고 태블릿·큰 글자·보조 메뉴에서도 같은 필수 행동에 접근하는지 살핀다.
5. 이름 없이 기기·막힌 행동·구간별 시간·학생이 설명한 장면 근거를 기록한다. 관찰자가 먼저 이동법이나 해석을 알려 주지 않는다.

## 화면과 입력

- 평소 필드 아래에 본문·목록·방향 버튼 영역이나 페이지 스크롤이 생기지 않는가.
- 대화와 게임 창에서 모든 글·선택·진행 단추에 접근하는가. 큰 글자에서도 창 안에서 내용을 온전히 읽는가.
- 대화·학습·설정 중 이동이 멈추고 닫은 뒤 필드 초점이 돌아오는가.
- 인물의 실제 그림과 눌리는 위치가 일치하며 필드 가장자리와 보조 메뉴에서도 같은 대상에 접근하는가.
- 입력 전에는 꿈이고 타격 뒤 새로 고침하면 선방으로 이어지는 것을 이해하는가.

소원 찾기와 맞대기의 첫 시도·도움은 학습 기록이다. 인연·구슬·해석을 점수나 소유물로 다루지 않는다. 해석은 근거와 함께 듣고 허무를 정답으로 강요하지 않는다. 준비 두 턴·성장 수치·적중 등급은 새 플레이의 학습 목표가 아니다.

## 모바일 방향 비교 — 2026-10-05

설치된 Chrome의 390×844 세로와 844×390 가로에서 일반·큰 글자 네 조건으로 실제 학생 시작→돌다리 대화→소원 선택을 진행했다. 모두 종료 0이며 문서 스크롤·대사 다음 단추 가림은 없었다. 캡처와 수치는 tests/shots/orientation-resume-*.png 및 orientation-resume.json, 실행 출력은 orientation-resume.log다.

현재의 세로 동선과 읽기 창에서는 세로 기본 유지가 타당하다는 판단이다. 가로는 좌우 시야가 넓지만 낮은 높이 때문에 대화가 인물 주변을 더 많이 가리며 읽기 창의 스크롤이 늘어난다. 방향을 강제로 잠그거나 회전 안내로 진행을 막지 않는다. 실제 학생의 손 조작·기기·선호는 별도 확인 대상이다.

별도 깨어남 자료의 실제 입력으로 지팡이도 같은 네 조건을 검사해 종료 0을 확인했다. 입력 전 awake:false, 가려지지 않은 타격 단추, 입력 후 awake:true와 같은 선방 복귀를 확인했다. 가로 큰 글자 캡처에서는 대사창이 호승의 하단 일부와 겹치지만 들어 올린 지팡이와 타격 단추는 보인다. 세로에서는 인물과 대사 사이의 여유가 더 크다. 증거는 tests/shots/orientation-staff-resume.log·json과 orientation-staff-*.png이며 본편 전체 완주 검증과 구분한다.

일지 재개·맞대기 입력과 해석·결과·긴 이름·PNG도 같은 네 조건에서 종료 0이다. 현재 회차와 최초 깨어남 시각을 유지하고 문서 바깥 스크롤이나 책 창의 가로 넘침 없이 진행했다. 결과의 대비 그림은 좁은 화면에서 위아래, 넓은 화면에서 나란히 보이며 원본 비율과 도트 배율을 유지한다. 증거는 tests/shots/t9-journal-layout.json, t9-results-layout.json과 같은 접두사의 로그·캡처·실제 내보낸 PNG다. 이 검사는 실제 플레이로 얻은 저장 기록을 재개한 화면 회귀이며, 별도의 선생님용·상태 주입 없는 전체 세 경로와 구분한다.

책 안쪽의 나무 무늬를 없애고 질문표에 불투명 바탕을 적용했다. 가로 큰 글자의 읽기 배경 한 점 표본은 명암비 약 2.52→11.42였고, 후속 네 조건에서 입력·스크롤·그림 저장 오류가 없었다. 표본은 전체 화면 최저 대비를 뜻하지 않는다. 이전 그림은 tests/shots/t7-resume-2026-10-05/orientation-resume-844x390-big-wish.png, 이후 그림은 tests/shots/t9-resume-2026-10-05/t9-journal-844x390-big.png다.

이 확인은 설치된 Chrome의 화면 크기 비교다. 실제 휴대폰/태블릿·Safari/Firefox와 실제 학생의 손 조작·몰입은 미확인이다. 이번 개편은 배포하지 않았으며 공개 URL 내용을 조회하지 않아 작업판과 공개판의 동일성도 미검증이다.

## 구판의 관찰·검증 기록

아래는 2026-10-04의 문서형·육성 구조를 확인한 기록이다. 이전 화면 결정과 검사 결과를 보존하며 새 탑다운 게임이나 실제 학생 관찰의 완료 증거로 사용하지 않는다.

### 당시 흐름과 조작

- 필수 조신 도입은 다른 작품과 구운몽을 혼동시킬 수 있었다. 성진의 돌다리 장면부터 시작하고, 결과에서 별개의 작품임과 비교 이유를 안내한 뒤 선택해 읽게 했다.
- 첫 사건 전에 긴 대사 안내부터 읽는 부담을 줄이려고 사건과 인물의 말 뒤에 안내를 배치했다.
- 그림 위의 긴 카드와 바닥 고정 단추는 글 잘림과 큰 여백을 만들었다. 그림 아래에 글을 온전히 펼치고 진행 단추를 바로 뒤에 둔다. 큰 글자·320px도 확인한다.
- 출가 컷신의 작은 건너뛰기 단추가 큰 최소 너비를 받아 가로로 넘쳤다. 보조 단추의 너비와 좁은 화면의 줄바꿈을 바로잡았다.
- 준비의 움직임·능력 변화, 사건의 대사·인연·물건·집 꾸밈, 말판 이동과 선택형 구슬 찾기는 사건마다 다른 변화를 제공한다. 준비·단서의 반복 틀 자체는 유지하며 실제 반복 피로는 학생 사용 후 확인한다.

### 당시 학습목표와 확인할 증거

| 목표 | 게임에서 학생이 하는 일 | 검증과 수업의 구분 |

꿈 점수와 해석 선택을 성적·등수로 쓰지 않는다. 인연·구슬은 점수나 소유물로 다루지 않는다. 조신 비교는 선택이며 읽어도 기록을 바꾸지 않는다.

실제 학급에서는 35~45분 완주 가능성, 같은 준비 틀의 반복 피로, 예고를 읽고 선택하는지, 결과의 근거를 자기 말로 설명하는지를 확인한다. 이 기록은 그러한 학생 실측을 마쳤다는 뜻이 아니다.
