# 풀지 못한 문제

## README의 웹 주소가 아직 열리지 않는다

- 증상: README '실행하기'가 https://pblsketch.github.io/guunmong/ 을 휴대폰·태블릿에 권하지만, 공개 전이라 이 주소는 열리지 않는다.
- 영향: 공개 전에 README를 본 교사·검토자가 링크를 눌러도 게임이 열리지 않는다.
- 지금 못 고치는 까닭: 공개(저장소 만들기·Pages 켜기)는 사용자 확인이 필요한 바깥 행동이다.
- 길: 공개하면 저절로 풀린다. 공개가 늦어지면 README에 "공개 예정"을 적는다.

## 교과서 본문 겹침 점검이 다른 기기에서는 조용히 통과한다

- 증상: `check-rights.mjs`와 `check-content.mjs`는 교과서 본문 추출본을 `E:/github/고전 문학 게임/구운몽/design/source/교과서_본문추출.txt`에서만 읽는다. 이 파일이 없는 기기·경로(다른 PC, 다른 폴더로 옮긴 사본)에서는 "건너뜀"을 찍고 종료 코드 0으로 끝난다.
- 영향: 그 기기에서 교과서 문장을 옮긴 글을 써도 완료 조건을 통과한다. 공개 전 마지막 권리 확인이 이 기기 밖에서 이뤄지면 겹침을 못 잡는다.
- 지금 못 고치는 까닭: 추출본 자체가 교과서 저작물이라 저장소에 넣을 수 없어, 경로를 받는 방식으로 점검 코드를 고쳐야 한다.
- 길: 환경 변수로 추출본 경로를 받게 하고, 경로가 없으면 실패하되 명시적 인자(예: `--no-textbook`)로만 건너뛰게 한다.

## 그림 생성 때 남은 Codex 자격 증명 복사본

- 증상: `tools/gen.ps1`이 예전에는 그림마다 `%TEMP%\codex-img-guun-<이름>\`에 `~/.codex/auth.json`을 복사하고 지우지 않았다. 2026-10-03 현재 이 기기에 그런 폴더가 73개 남아 있다. 지금의 `gen.ps1`은 생성이 끝나면 그 복사본을 지운다.
- 영향: 남은 폴더에 로그인 토큰 복사본이 있다. 임시 폴더를 백업하거나 공유하면 함께 나간다.
- 지금 못 고치는 까닭: 이미 남은 폴더를 지우는 일은 사용자 기기의 파일 삭제라 사용자 판단이 필요하다.
- 길: 사용자 확인 뒤 `%TEMP%\codex-img-guun-*` 폴더를 지운다.

## 공개 주소를 대상으로 자동 점검을 돌릴 수 없다

- 증상: 모든 점검이 저장소 폴더를 자기 로컬 서버로 띄워 연다. 공개한 GitHub Pages 주소를 대상으로 학생 완주를 돌리는 옵션이 없다.
- 영향: 공개 뒤 경로(대소문자, 한글 파일 이름, Pages의 MIME 형식) 문제가 생겨도 자동으로 잡지 못한다.
- 지금 못 고치는 까닭: 공개 전이라 대상 주소가 없고, 점검 코드에 주소를 받는 옵션을 더해야 한다.
- 길: check-content에 대상 주소를 받는 환경 변수(예: `BASE_URL`)를 더해 로컬 서버 대신 그 주소로 완주한다.

## 게임 그림 하나만 다시 가공할 수 없다

- 증상: 가공 스크립트는 `assets/raw/<이름>.png`(생성 원본, git 제외)를 읽는데, 이 기기의 `assets/raw/`에는 화풍 시안 네 장만 남아 있다.
- 영향: README '알려진 한계'의 작은 어긋남(구경하는 승려의 머리, 봉래전 양소유의 관모 등)이나 색 줄이기 조정을 하려 해도 새로 생성해야 하고, 새 생성은 원래 그림과 얼굴·구도가 달라질 수 있다.
- 지금 못 고치는 까닭: 원본은 이미 없고, 새 생성은 그림을 사용자에게 먼저 보여 확인받아야 하는 일이다.
- 길: 고칠 그림을 정하면 같은 프롬프트로 다시 생성해 모아 보기로 확인받는다. 앞으로는 생성 원본을 저장소 밖 한곳에 보관한다.
