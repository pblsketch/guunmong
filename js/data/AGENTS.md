# js/data — 게임 내용

## 맡는 것과 형식

인물·장 안내·맵·체험·위기 도전과 생각 선택·본편 28단위와 선택형 비교 자료·소원·인연·집·꿈 일지·해석·노트·음원·동작 그림 목록을 둔다. 형식의 단일 기준은 이 폴더의 README.md이며 새 필드는 먼저 문서화한다.

데이터는 GUUN에 값을 대입하는 일만 한다. 함수·getter·G 호출은 금지다. bgm.js는 생성 도구가 관리하므로 손으로 고치지 않는다. 시험 자료는 tests/fixtures에만 두고 실제 자료에 임시 문구를 넣지 않는다.

## 원작과 선택

- 진행 순서와 결말을 바꾸지 않는다. 사건 12개와 남전산·하북·봉래전 이음을 원작 순서에 둔다.
- 사건 본문은 scenes.lines에 한 번만 적고 experiences의 행동이 줄 인덱스로 참조한다. maps와 experiences는 README 계약을 따르며 모든 대상·효과·장소 전환·필수 경로를 검사한다. preview/clues/core/gradeText는 구판 호환 필드이며 새 체험에서 쓰지 않는다(말판 square는 0022에서 지웠다). 남아 있는 구판 단서와 인연 보호 검사는 유지한다.
- 가춘운·적경홍에서는 소유가 원작대로 속는다. 미리 간파·회피하거나 난양공주를 혼례 전에 직접 만나는 장면을 넣지 않는다. 전투·사냥·분기 결말도 만들지 않는다.
- 인연은 등급별 필드·채움·능력·자원·보상을 갖지 않는다. 미색을 fills에 넣지 않는다. 처음 만나는 사건 여덟 곳에만 meet와 구슬을 둔다.
- 정경패 명주는 한문 계열 근거이며 완판 대조 미확인 안내를 지킨다. 난양공주 명주는 두 계열 근거다. 다른 여섯 구슬은 게임 설정으로 표시한다. 구슬은 정답 평가 대상이 아니다.
- 소원 찾기의 정답 다섯은 독백에 실제로 있고, 다른 분명한 바람을 오답으로 쓰지 않는다. 맞대기 다섯 짝만 채점하며 인연 잇기와 해석은 채점하지 않는다.
- 정답은 을사본 한문 계열과 한글 완판본의 공통 사실만 사용한다. 이본별 곡명·글자·꽃잎 수·조신의 햇수·삭발·하북 직함 등을 정답으로 묻지 않는다. 장주의 나비는 해석 근거로만 다룬다.

## 글과 자산

- 대사·풀이는 새로 쓴다. 교과서 본문과 15자 이상 겹치는 글, 금지된 출판사·교사 자료 사이트 이름을 넣지 않는다. 조사 두 꼴도 쓰지 않는다.
- 전체 이야기 음절은 5,000 이하이며 G.storyText 기준이다. 새 월드가 참조한 본문·소원 독백과 서술·대사의 응답·결말, 도전의 반응·뒤 장면 안내, 되짚기 틀과 E11(가장 길게 채운 꼴)을 센다. 틀이 아닌 근거 열 개는 실제로 읽는 줄에 있어야 한다.
- 해석은 선택지 네 개·근거 열한 개(틀 근거 E11 포함)다. 응답에서 나온 세 근거에는 after를 둔다.
- 선택지의 소원 증감(`wish`)은 출장입상·부귀·풍류·공명만, ±1만 쓴다. 미색은 움직이지 않는다. 풍류 증감은 `music:true` 자리에서만, 여인 앞에서는 만남이 아니라 고른 말의 성격만 반영한다. 생각 선택 자리마다 물러남(`stay`) 하나. 증감 표의 방향을 바꾸려면 사용자에게 묻는다. 마음 고르기·다시 읽기 extra·직접 집 배치는 없다.
- 현재 orig는 없다. 대조 전 회목은 status를 유지하고 영인 대조를 끝낸 글만 orig/src로 바꾸며 검사 기준도 함께 고친다.
- say와 호칭 링크는 얼굴이 있는 인물만 가리키며 mood는 등록값만 사용한다. 다른 인물은 서술에서 이름으로 부른다.
- 실제 그림과 곡만 가리킨다. 기존 bgm의 18곡 정의는 고치지 않고 장면 배정만 한다.
- sprites는 승인된 파일의 src/width/height/frames/rows다. 현행 걷기는 32×32/5프레임/4행과 cell/anchor/directions, 정지 NPC는 32×32/1프레임/1행이다. 호승과 구판 준비 네 가지는 96×96/4프레임, 구판 아이콘은 32×32/1프레임이다. 호승 2번 올림·3번 타격을 보존한다. 미등록 그림의 대체 표시를 실제 필수 승인 자산 누락의 통과 근거로 쓰지 않는다.
- 생활 공간의 fromStory는 임명 행동의 원작 사실을 가리킨다. 승상부는 e11 임명 확정 뒤에 열며, 옛 실제 완료의 호환 사실은 새 행동으로 만들지 않는다. e10의 작은 꿈은 map-yoyeon 진영으로 복귀하며 awake를 쓰지 않는다.
- v3 배포 뒤 진행·활동·선택 자리·도전 id를 바꿔 저장을 깨뜨리지 않는다. 첫 선방과 마지막 선방은 map-cell을 공유한다. 실제 자산은 승인 키만 쓰며 placeholder는 명시 시험 프로필에만 허용한다. 소원 사실 id는 e08-wonsu:appointment, e11-seungsang:appointment, e11-seungsang:portrait를 사용한다.

## 고친 뒤

node tests/check-data.mjs로 순서·공통 사실 대응·글 수·근거·파일·교과서 겹침을 확인한다. 본문 대조 파일이 없으면 이 검사는 실패한다. 새 표시 문자는 python tools/build_fonts.py로 글꼴에 넣고 함께 반영한다. 실제 학생 완주는 check-content, 그림·음원은 check-assets/check-bgm으로 확인하며 마지막은 node tests/run-all.mjs 종료 0이다.
