# js/data — 게임 내용

## 맡는 것
게임에 나오는 모든 글과 문항과 배치: 인물(`people`), 장 안내(`chapters`), 말판 칸(`board`), 장면 27개(`scenes`), 소원(`wishes`), 인연(`bonds`), 집 단계(`house`), 꿈 일지 짝(`journal`), 해석(`interp`), 노트·교사용 안내·화면 문구 일부(`notes`), 배경음 배정(`bgm`).

**형식의 유일한 기준은 이 폴더의 `README.md`다.** 항목을 더하거나 모양을 바꾸려면 README에 먼저 적는다.

## 맡지 않는 것
- `bgm.js`는 `tools/make_bgm.py`가 만든다. 손으로 고치면 다음 실행 때 사라진다.
- 임시 데이터는 `tests/fixtures/`에 둔다. 여기에 `(임시)`·`TODO`가 있으면 점검이 실패한다.
- 화면 동작(채움 계산, 잠금, 장부)은 `js/core`·`js/game`이 한다. 데이터에 함수나 getter를 두지 않는다(점검이 node에서 이 파일들을 그대로 실행해 읽는다).

## 지켜야 할 것
- 장면은 장 순서대로, 같은 장 안에서는 원작 순서대로 적는다. 결말과 사건을 바꾸지 않는다. 웃음 연출은 대사·표정만 바꾸고, 원작에 없는 한마디는 처음 나오는 곳에 게임 설정 카드(`fc-comic`)로 밝힌다.
- 미색(`dreamHidden`)을 어떤 `fills`에도 넣지 않는다. 인연 카드에 `fills`·`wish`를 두지 않고, 일지 짝의 `event`에 인연 id를 두지 않는다. 풍류는 음악·악기로만 채운다(시회는 공명).
- 말판 칸은 `office`·`place`만, 떨어지는 칸 없음. 구슬은 `meet`가 있는 장면(여인을 처음 만나는 여덟 장면)에만, 근거가 원작이면 `trace: 'canon'`(정경패·난양공주 둘뿐), 나머지는 `'fiction'`.
- 활동은 `slots` 틀만. 채점 활동의 모든 칸에 `answer`. 정답은 을사본 한문 계열과 한글 완판본에 **모두 있는 사실**로만 정한다. 쓰면 안 되는 것: 양류사의 글자, 거문고 여덟째 곡 이름, 복숭아꽃 꽃잎 수·염주 이야기, 장주의 나비(해석 근거 후보로만), 팔선녀 삭발 세부, 조신의 햇수, 하북 행차의 '절도사'. 소원 찾기에서 "임금께 예를 다하고 백성을 이롭게 함"을 오답으로 쓰지 않는다.
- 마음 선택지는 모두 원문으로 읽어 낼 수 있는 마음이고 `scored`를 두지 않는다. 해석 선택지는 3~4개.
- 原文: 지금은 대조 전이라 어디에도 `orig`가 없다. 회목은 `heading: { hoe, part, gloss, status: '대조 대기' }`. 영인 대조를 마친 것만 `orig`·`src`를 더하고 `status`를 지우며, 그때 내용 점검의 '原文 없음' 기준을 같은 커밋에서 바꾼다. 전사본의 의심 글자를 대조 없이 고치지 않는다.
- 풀이·대사는 새로 쓴다. 교과서·지도서·번역서 문장을 옮기지 않고, 교과서 본문과 15자 이상 이어서 같은 글을 쓰지 않는다. 교과서 출판사 이름과 교사 자료 사이트 이름을 쓰지 않는다(교과 연계는 "공통국어2 「구운몽」 단원"처럼).
- `{호칭|id}`와 `say`는 얼굴 그림이 있는 인물만 가리킨다(`noFace: true` 인물은 이름만). 표정은 그 인물의 `moods`에 있는 것만.
- 그림 이름(`img`·`imgAfter`·`roomImg`, 물건 `img`, 집 `img`)과 곡 이름은 README의 에셋 약속을 따른다. 없는 그림을 가리키면 점검이 실패한다.
- 공개한 뒤에는 장면·활동 id를 바꾸지 않는다(학생 기기의 저장이 id로 기록을 가리킨다).
- 조사 두 꼴(`을(를)` 등)을 쓰지 않는다.

## 고친 뒤
1. `python tools/build_fonts.py` — 새 글자가 생기면 글꼴에 넣는다. 안 하면 그 글자만 다른 글꼴로 보이고 점검은 잡지 못한다.
2. `cd tests; node check-content.mjs` — 데이터 규칙, `G.checkData()` 경고 0, 금칙어, 조사, 교과서 15자 겹침, 실제 데이터 완주 세 판.
3. 그림·곡 이름을 바꿨으면 `node check-assets.mjs`, `node check-bgm.mjs`. 마지막에 `node run-all.mjs`.
4. 고친 데이터와 다시 만든 글꼴을 같은 커밋에 넣는다.
